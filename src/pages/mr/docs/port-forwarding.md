# पोर्ट फॉरवर्डिंग

Mobile SSH Android आणि iOS या दोन्हींवर स्थानिक SSH पोर्ट फॉरवर्डिंगला समर्थन देते. उपकरणावरील एक स्थानिक पोर्ट `127.0.0.1` वर ऐकतो आणि SSH कनेक्शनद्वारे रहदारी रिमोट होस्ट आणि पोर्टकडे फॉरवर्ड करतो.

## जतन केलेल्या टनेलची वाक्यरचना

पोर्ट-फॉरवर्डिंग नियम स्वल्पविरामाने वेगळे केले जातात. प्रत्येक नोंद दोनपैकी एक स्वरूप वापरते:

```text
PORT
LOCAL:REMOTEHOST:REMOTE
```

संक्षिप्त स्वरूप:

```text
8080
```

हे उपकरणावर `127.0.0.1:8080` बांधते आणि सर्व्हरच्या दृष्टिकोनातून ते `localhost:8080` कडे फॉरवर्ड करते.

पूर्ण स्वरूप:

```text
3000:localhost:3000
```

हे उपकरणावर `127.0.0.1:3000` बांधते आणि SSH द्वारे ते रिमोट बाजूच्या `localhost:3000` कडे फॉरवर्ड करते.

अनेक फॉरवर्ड:

```text
8080, 3000:localhost:3000, 15432:db.internal:5432
```

## जतन केलेल्या सर्व्हरमध्ये टनेल जोडा

1. **Saved Servers** उघडा.
2. सर्व्हर प्रोफाइल जोडा किंवा संपादित करा.
3. **Port forwards** मध्ये फॉरवर्डिंग नियम प्रविष्ट करा.
4. सर्व्हर जतन करा.
5. सर्व्हरशी जोडा.

SSH सत्र जोडल्यानंतर अ‍ॅप जतन केलेले फॉरवर्ड लागू करते.

## टनेल सर्व्हर प्रोफाइलचेच असतात

फॉरवर्ड जतन केलेल्या सर्व्हरवर घोषित केले जातात आणि तो सर्व्हर जोडला जातो तेव्हा ते सुरू होतात. सत्र चालू असताना टनेल जोडण्यासाठी किंवा काढण्यासाठी दोन्हींपैकी कोणत्याही प्लॅटफॉर्मवर वेगळी स्क्रीन नाही: तुमचे फॉरवर्ड बदलण्यासाठी सर्व्हर प्रोफाइल संपादित करा आणि पुन्हा जोडा.

ही जाणीवपूर्वक केलेली तडजोड आहे — प्रोफाइलमध्ये राहणारा टनेल तुम्ही जोडता तेव्हा प्रत्येक वेळी परत येतो, नव्या नेटवर्कवर पुन्हा जोडल्यानंतरही, आणि तो हाताने पुन्हा उभारावा लागत नाही.

## IPv6 गंतव्ये

IPv6 गंतव्य कंसात लिहावेच लागते, जेणेकरून त्यातील कोलन पोर्ट विभाजकाशी गोंधळून जाऊ नयेत:

```text
8080:[2001:db8::1]:80
```

कंसाशिवाय लिहिलेला IPv6 पत्ता गुपचूप चुकीचा वाचण्याऐवजी संदिग्ध म्हणून नाकारला जातो. हेच कंसाचे स्वरूप सर्व्हरच्या पत्ता क्षेत्रातही चालते, त्यानंतर पर्यायी पोर्टसह (`[fe80::1]:22`).

## पत्ता बंधन

Mobile SSH स्थानिक फॉरवर्ड उपकरणावरील `127.0.0.1` ला बांधते. हे जाणूनबुजून आहे: ते टनेल उपकरण-स्थानिक ठेवते आणि फक्त-IPv6 लूपबॅक संबंधित अनपेक्षित समस्या टाळते. ऑपरेटिंग सिस्टम त्यांच्या नेटवर्क प्रवेशास परवानगी देत असल्यास त्याच उपकरणावरील इतर अ‍ॅप्स फॉरवर्ड केलेल्या स्थानिक पोर्टशी जोडू शकतात.

## सामान्य उदाहरणे

रिमोट सर्व्हरवर चालणाऱ्या वेब सेवेपर्यंत प्रवेश:

```text
8080
```

मग त्याच उपकरणावरील ब्राउझरमधून `http://127.0.0.1:8080` उघडा.

डेव्हलपमेंट सर्व्हरपर्यंत प्रवेश:

```text
3000:localhost:3000
```

SSH सर्व्हरवरून पोहोचता येणाऱ्या अंतर्गत डेटाबेसपर्यंत प्रवेश:

```text
15432:db.internal:5432
```

## टनेल समस्या निवारण

- SSH सत्र जोडलेले असल्याची खात्री करा — सत्र जोडल्यानंतरच फॉरवर्ड सुरू होतात.
- स्थानिक पोर्ट आधीच वापरात नाही हे तपासा.
- रिमोट होस्ट आणि पोर्ट SSH सर्व्हरवरून पोहोचता येतात हे तपासा.
- गंतव्य सेवा SSH सर्व्हरवरच असल्यास `localhost` वापरा.
- SSH सर्व्हरच्या मागे दुसऱ्या होस्टकडे फॉरवर्ड करताना सर्व्हरचे अंतर्गत DNS नाव किंवा IP वापरा.
