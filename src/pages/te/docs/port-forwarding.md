# పోర్ట్ ఫార్వార్డింగ్

Mobile SSH Android మరియు iOS రెండింటిలోనూ లోకల్ SSH పోర్ట్ ఫార్వార్డింగ్‌ను మద్దతిస్తుంది. పరికరంలోని ఒక లోకల్ పోర్ట్ `127.0.0.1` పై వింటుంది మరియు SSH కనెక్షన్ ద్వారా ట్రాఫిక్‌ను రిమోట్ హోస్ట్ మరియు పోర్ట్‌కు ఫార్వార్డ్ చేస్తుంది.

## సేవ్ చేసిన టన్నెల్ సింటాక్స్

పోర్ట్-ఫార్వార్డింగ్ నియమాలు కామాతో వేరు చేయబడతాయి. ప్రతి ఎంట్రీ రెండు రూపాల్లో ఒకదాన్ని ఉపయోగిస్తుంది:

```text
PORT
LOCAL:REMOTEHOST:REMOTE
```

చిన్న రూపం:

```text
8080
```

ఇది పరికరంలో `127.0.0.1:8080`ను బైండ్ చేసి, సర్వర్ దృష్టికోణం నుండి దాన్ని `localhost:8080`కు ఫార్వార్డ్ చేస్తుంది.

పూర్తి రూపం:

```text
3000:localhost:3000
```

ఇది పరికరంలో `127.0.0.1:3000`ను బైండ్ చేసి, SSH ద్వారా దాన్ని రిమోట్ వైపు `localhost:3000`కు ఫార్వార్డ్ చేస్తుంది.

బహుళ ఫార్వార్డ్‌లు:

```text
8080, 3000:localhost:3000, 15432:db.internal:5432
```

## సేవ్ చేసిన సర్వర్‌కు టన్నెల్ జోడించడం

1. **Saved Servers** తెరవండి.
2. సర్వర్ ప్రొఫైల్‌ను జోడించండి లేదా సవరించండి.
3. **Port forwards**లో ఫార్వార్డింగ్ నియమాలను నమోదు చేయండి.
4. సర్వర్‌ను సేవ్ చేయండి.
5. సర్వర్‌కు కనెక్ట్ అవ్వండి.

SSH సెషన్ కనెక్ట్ అయిన తర్వాత యాప్ సేవ్ చేసిన ఫార్వార్డ్‌లను వర్తింపజేస్తుంది.

## టన్నెల్‌లు సర్వర్ ప్రొఫైల్‌కు చెందుతాయి

ఫార్వార్డ్‌లు సేవ్ చేసిన సర్వర్‌పై ప్రకటించబడతాయి, మరియు ఆ సర్వర్ కనెక్ట్ అయినప్పుడు అవి పైకి వస్తాయి. సెషన్ మధ్యలో టన్నెల్‌ను జోడించడానికి లేదా తీసివేయడానికి ఏ ప్లాట్‌ఫారమ్‌లోనూ ప్రత్యేక స్క్రీన్ లేదు: మీ ఫార్వార్డ్‌లను మార్చాలంటే సర్వర్ ప్రొఫైల్‌ను సవరించి మళ్లీ కనెక్ట్ అవ్వండి.

ఇది ఉద్దేశపూర్వక రాజీ — ప్రొఫైల్‌లో ఉండే టన్నెల్ మీరు కనెక్ట్ అయిన ప్రతిసారీ తిరిగి వస్తుంది, కొత్త నెట్‌వర్క్‌లో మళ్లీ కనెక్ట్ అయిన తర్వాత కూడా, మీరు దాన్ని చేతితో మళ్లీ నిర్మించనవసరం లేకుండా.

## IPv6 గమ్యస్థానాలు

IPv6 గమ్యస్థానాన్ని బ్రాకెట్లలో ఉంచాలి, తద్వారా కోలన్‌లను పోర్ట్ విభాజకంతో గందరగోళపరచలేరు:

```text
8080:[2001:db8::1]:80
```

బ్రాకెట్లు లేని ఖాళీ IPv6 చిరునామాను నిశ్శబ్దంగా తప్పుగా అర్థం చేసుకునే బదులు అస్పష్టమైనదిగా తిరస్కరిస్తారు. అదే బ్రాకెట్ రూపం సర్వర్ చిరునామా ఫీల్డ్‌లో కూడా పనిచేస్తుంది, దాని తర్వాత ఐచ్ఛిక పోర్ట్‌తో (`[fe80::1]:22`).

## చిరునామా బైండింగ్

Mobile SSH లోకల్ ఫార్వార్డ్‌లను పరికరంలో `127.0.0.1`కు బైండ్ చేస్తుంది. ఇది ఉద్దేశపూర్వకం: ఇది టన్నెల్‌ను పరికర-లోకల్‌గా ఉంచి, IPv6-మాత్రమే లూప్‌బ్యాక్ ఆశ్చర్యాలను నివారిస్తుంది. ఆపరేటింగ్ సిస్టమ్ వారి నెట్‌వర్క్ యాక్సెస్‌ను అనుమతిస్తే, అదే పరికరంలోని ఇతర యాప్‌లు ఫార్వార్డ్ చేసిన లోకల్ పోర్ట్‌కు కనెక్ట్ అవ్వవచ్చు.

## సాధారణ ఉదాహరణలు

రిమోట్ సర్వర్‌లో నడుస్తున్న వెబ్ సేవను యాక్సెస్ చేయడం:

```text
8080
```

ఆపై అదే పరికరంలో బ్రౌజర్ నుండి `http://127.0.0.1:8080` తెరవండి.

డెవలప్‌మెంట్ సర్వర్‌ను యాక్సెస్ చేయడం:

```text
3000:localhost:3000
```

SSH సర్వర్ నుండి చేరుకోగల అంతర్గత డేటాబేస్‌ను యాక్సెస్ చేయడం:

```text
15432:db.internal:5432
```

## టన్నెల్ సమస్య పరిష్కారం

- SSH సెషన్ కనెక్ట్ అయిందని నిర్ధారించుకోండి — సెషన్ ఏర్పడిన తర్వాతే ఫార్వార్డ్‌లు పైకి వస్తాయి.
- లోకల్ పోర్ట్ ఇప్పటికే వాడుకలో లేదని తనిఖీ చేయండి.
- రిమోట్ హోస్ట్ మరియు పోర్ట్ SSH సర్వర్ నుండి చేరుకోగలవని తనిఖీ చేయండి.
- గమ్య సేవ SSH సర్వర్‌లోనే ఉన్నప్పుడు `localhost` ఉపయోగించండి.
- SSH సర్వర్ వెనుక ఉన్న మరో హోస్ట్‌కు ఫార్వార్డ్ చేసేటప్పుడు సర్వర్ అంతర్గత DNS పేరు లేదా IP ఉపయోగించండి.
