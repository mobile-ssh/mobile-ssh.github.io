# టర్మినల్

Mobile SSH టర్మినల్ ఫోన్ మరియు టాబ్లెట్ నిర్వహణ కోసం రూపొందించబడింది. ఇది ఒక టర్మినల్ కాన్వాస్, అదనపు కీ వరుస, బహుళ-సెషన్ పేన్‌లు, స్క్రోల్ నిర్వహణ మరియు పునఃకనెక్షన్ ప్రవర్తనను కలుపుతుంది.

## టర్మినల్ ప్రాథమికాలు

- టర్మినల్ రంగు మద్దతు మరియు కర్సర్-కీ నిర్వహణతో xterm-శైలి ప్రవర్తనను ఉపయోగిస్తుంది.
- స్క్రోల్‌బ్యాక్ బఫర్ గరిష్టంగా 5000 లైన్‌లను ఉంచుతుంది.
- టైప్ చేయడానికి ముందు పేన్‌ను ఎంచుకోవడానికి దాన్ని నొక్కండి.
- టెక్స్ట్ పరిమాణాన్ని మార్చడానికి టర్మినల్ పేన్‌ను పించ్ చేయండి. సంజ్ఞ స్థిరపడిన తర్వాత Mobile SSH రిమోట్ PTY పరిమాణాన్ని మారుస్తుంది.
- ఫుల్‌స్క్రీన్ మోడ్‌లోకి ప్రవేశించడానికి పేన్‌పై డబుల్-ట్యాప్ చేయండి (లేదా దాని విస్తరణ నియంత్రణను ఉపయోగించండి). గ్రిడ్‌కు తిరిగి రావడానికి Android‌లో Back, లేదా iOS‌లో కుదించే నియంత్రణను ఉపయోగించండి.

## బహుళ-సెషన్ గ్రిడ్

Mobile SSH ఒకేసారి ఎనిమిది SSH సెషన్‌ల వరకు నడపగలదు. ప్రతి సెషన్ టర్మినల్ గ్రిడ్‌లో ఒక పేన్‌గా కనిపిస్తుంది. పేన్ హెడర్ ప్రస్తుత లక్ష్యం లేదా శీర్షికను చూపుతుంది. ఎంచుకోవడానికి పేన్‌ను నొక్కండి, లేదా మరో కనెక్షన్‌ను ప్రారంభించడానికి **+ Add Session** ఉపయోగించండి.

పేన్‌ను మూసివేయడం ఆ SSH సెషన్‌ను డిస్‌కనెక్ట్ చేస్తుంది. స్టార్ట్ స్క్రీన్‌కు తిరిగి రావడం క్రియాశీల సెషన్‌లను **Active Sessions** ద్వారా అందుబాటులో ఉంచుతుంది.

## అదనపు కీ వరుస

Android మరియు iOS రెండింటిలోనూ, అదనపు కీ వరుస ఆన్-స్క్రీన్ కీబోర్డ్‌పైన కనిపిస్తుంది మరియు టచ్ కీబోర్డ్‌లపై ఇబ్బందికరమైన టర్మినల్ కీలను అందిస్తుంది:

- `ESC`
- `TAB`
- `CTRL`
- `Shift`
- బాణం కీలు
- `HOME`
- `END`
- `PGUP`
- `PGDN`
- కీబోర్డ్ టోగుల్

`CTRL` మరియు `Shift` తదుపరి అనుకూల ఇన్‌పుట్ కోసం స్టిక్కీ మాడిఫైయర్‌లుగా పనిచేస్తాయి. ఉదాహరణకు, `CTRL` నొక్కి, ఆపై Ctrl-C పంపడానికి `C` టైప్ చేయండి.

## కీబోర్డ్ ప్రవర్తన

Mobile SSH లో కీబోర్డ్‌కు సంబంధించిన రెండు సెట్టింగ్‌లు ఉన్నాయి:

- **కీబోర్డ్ చూపడానికి టర్మినల్‌ను నొక్కండి:** ప్రారంభించబడితే, టర్మినల్‌ను నొక్కడం ఆన్-స్క్రీన్ కీబోర్డ్‌ను చూపమని సిస్టమ్‌ను అడుగుతుంది.
- **కీబోర్డ్ సూచనలు:** ప్రారంభించబడితే, అనుకూల కీబోర్డ్‌లు షెల్ ప్రాంప్ట్‌లలో సూచనలను చూపవచ్చు. సూచనలు టర్మినల్ ప్రోగ్రామ్‌లకు ఆటంకం కలిగిస్తే దీన్ని నిలిపివేయండి.

సూచనలు ప్రారంభించబడినప్పుడు, Mobile SSH కంపోజ్ అవుతున్న టెక్స్ట్‌ను పద-సరిహద్దు వరకు బఫర్ చేస్తుంది, తద్వారా రిమోట్ షెల్‌కు పంపే ముందు కీబోర్డ్ సవరణ ప్రస్తుత పదాన్ని భర్తీ చేయగలదు. కంట్రోల్ కీలు మరియు టర్మినల్ చార్డ్‌లు ఆ బఫర్‌ను దాటవేస్తాయి, కాబట్టి tmux ప్రిఫిక్స్ కమాండ్‌ల వంటి షార్ట్‌కట్‌లు వెంటనే చేరతాయి.

Android‌లో, వాయిస్ ఇన్‌పుట్ (Gboard మైక్రోఫోన్ బటన్) అదే కంపోజింగ్-టెక్స్ట్ బఫర్ గుండా వెళుతుంది, కాబట్టి చెప్పిన టెక్స్ట్ అక్షరం-అక్షరంగా కాకుండా పరిష్కరించబడిన తర్వాత ఒకసారి పంపబడుతుంది.

## ఎంచుకోండి, కాపీ చేయండి, షేర్ చేయండి

ఎంపిక మోడ్‌లోకి ప్రవేశించడానికి టర్మినల్ లోపల ఎక్కువసేపు నొక్కండి. ఎంపిక టూల్‌బార్ మూడు చర్యలను అందిస్తుంది:

- **Copy** — ఎంచుకున్న టెక్స్ట్‌ను సిస్టమ్ క్లిప్‌బోర్డ్‌లో ఉంచుతుంది.
- **Share** — ఎంచుకున్న టెక్స్ట్‌ను సిస్టమ్ షేర్ షీట్‌కు (మెయిల్, నోట్స్, మెసేజింగ్ మొ.) పంపుతుంది.
- **Select all** — ఎంపికను పూర్తి కనిపించే టర్మినల్ బఫర్‌కు విస్తరిస్తుంది, ఆపై Copy లేదా Share ఉపయోగించవచ్చు.

## స్క్రోలింగ్

Mobile SSH టర్మినల్ స్థితి ఆధారంగా స్క్రోల్ సంజ్ఞలను మళ్లిస్తుంది:

- సాధారణ షెల్ అవుట్‌పుట్‌లో, స్వైప్ చేయడం లోకల్ స్క్రోల్‌బ్యాక్ బఫర్‌ను స్క్రోల్ చేస్తుంది.
- మౌస్-మోడ్ టర్మినల్ యాప్‌లలో, స్క్రోలింగ్ మౌస్-వీల్ ఎస్కేప్ సీక్వెన్స్‌లను పంపుతుంది.
- మౌస్ మోడ్ లేని ప్రత్యామ్నాయ-స్క్రీన్ యాప్‌లలో, చాలా tmux సెషన్‌ల వంటివి, స్క్రోలింగ్ tmux కాపీ మోడ్‌లోకి ప్రవేశించి లైన్ స్క్రోల్ కమాండ్‌లను పంపుతుంది.

మీరు వెనక్కి స్క్రోల్ చేసిన స్థితిలో టైప్ చేస్తే, Mobile SSH లైవ్ టర్మినల్ వీక్షణకు తిరిగి వస్తుంది.

## tmux ప్రవర్తన

Mobile SSH బయటకు వెళ్లే tmux attach మరియు new-session కమాండ్‌లను గమనిస్తుంది, ఉదాహరణకు:

```bash
tmux attach -t work
tmux a -t work
tmux new -A -s work
```

మీరు tmux లో ఉన్నప్పుడు కనెక్షన్ తెగిపోతే, యాప్ ఆ సర్వర్ కోసం చివరి tmux సెషన్ పేరును గుర్తుంచుకుని, పునఃకనెక్షన్ తర్వాత మళ్లీ అటాచ్ చేయడానికి ప్రయత్నించవచ్చు. స్పష్టమైన సెషన్ పేరు గమనించబడకపోయినా, మీరు ప్రత్యామ్నాయ-స్క్రీన్ tmux-వంటి సెషన్‌లో ఉన్నారని యాప్‌కు తెలిస్తే, అది సాధారణ `tmux attach` ప్రయత్నించవచ్చు.

ఈ ప్రవర్తన ఉత్తమ-ప్రయత్నం. రిమోట్ tmux సెషన్ ఇకపై లేకపోతే, రిమోట్ షెల్ అందుబాటులో ఉంటుంది.

## Agent alerts

Mobile SSH క్రియాశీల సెషన్ యొక్క టర్మినల్ అవుట్‌పుట్‌ను పర్యవేక్షించి, రిమోట్ ఏజెంట్ ఇన్‌పుట్ కోసం వేచి ఉందని సూచించే నమూనాలను గుర్తిస్తుంది. ఒక సరిపోలిక కనుగొనబడినప్పుడు — ఉదాహరణకు, Claude Code లేదా Codex ప్రాంప్ట్ కోసం ఆగినప్పుడు — యాప్ ఐచ్ఛిక శబ్దం మరియు వైబ్రేషన్‌తో నోటిఫికేషన్ పంపుతుంది.

కాన్ఫిగర్ చేయడానికి:

1. స్టార్ట్ స్క్రీన్ నుండి **Settings** తెరవండి.
2. **Agent alerts** ప్రారంభించండి.
3. నోటిఫికేషన్ శబ్దం మరియు వైబ్రేషన్ నమూనాను ఎంచుకోండి.

హెడ్‌ఫోన్‌లతో సహా ఏ ఆడియో అవుట్‌పుట్ క్రియాశీలంగా ఉన్నా అలర్ట్ దాని ద్వారా వినబడుతుంది, కాబట్టి వీడియో చూస్తున్నప్పుడు లేదా ఫోన్ లాక్ అయినప్పుడు కూడా వినవచ్చు. Mobile SSH నేపథ్యంలో ఉన్నప్పుడు కూడా నోటిఫికేషన్ కనిపిస్తుంది.

Agent alert నమూనాలు కనిపించే టర్మినల్ అవుట్‌పుట్‌తో సరిపోల్చబడతాయి. మీ రిమోట్ సాధనం గుర్తించదగిన ప్రాంప్ట్ లైన్ (వినియోగదారు పేరు, `?`, బ్రాకెట్‌లో ప్రశ్న) అవుట్‌పుట్ చేస్తే, యాప్ దాన్ని స్వయంచాలకంగా గుర్తించవచ్చు. అలర్ట్‌లు చాలా తరచుగా లేదా అస్సలు రాకపోతే, Settings లో సున్నితత్వాన్ని సర్దుబాటు చేయండి.

## ఫుల్-స్క్రీన్ టర్మినల్ ప్రోగ్రామ్‌లు

Vim, less, htop, ncurses సాధనాలు మరియు tmux పేన్‌ల వంటి ప్రోగ్రామ్‌ల కోసం:

- ప్రోగ్రామ్ ఊహించని విధంగా కీబోర్డ్ ఇన్‌పుట్‌ను బఫర్ చేయడం ప్రారంభిస్తే కీబోర్డ్ సూచనలను నిలిపివేయండి.
- `ESC`, బాణాలు, `PGUP` మరియు `PGDN` కోసం అదనపు కీ వరుసను ఉపయోగించండి.
- టెక్స్ట్ చాలా చిన్నగా ఉంటే పించ్ జూమ్ ఉపయోగించి, ఆపై రిమోట్ టర్మినల్ పరిమాణం స్థిరపడే వరకు కొద్దిసేపు వేచి ఉండండి.
