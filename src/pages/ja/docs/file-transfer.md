# ファイル転送

Mobile SSH には、アクティブな SSH 接続に結び付いた SFTP ファイル転送画面があります。スマートフォンやタブレットからの素早いサーバーメンテナンス向けです。設定をアップロードする、ログをダウンロードする、リモートファイルの名前を変更する、権限を確認する、といった操作をアプリを離れずに行えます。

## ファイル転送を開く

1. SSH サーバーに接続します。
2. 接続済みのターミナルペインを選びます。
3. ターミナルのツールバーから **Transfer** を開くか、現在の画面が対応していればペインのヘッダーを長押しします。
4. ローカルペインとリモートペインのあるファイル転送画面が開きます。

アクティブな SSH セッションがない場合、ファイル転送は開けません。

## ローカルペインとリモートペイン

ファイル転送画面には 2 つの参照ペインがあります。

- **ローカルペイン：** 端末のストレージ。
- **リモートペイン：** SFTP 経由のサーバーファイル。

最近のリモートパスと並び順をホストごとに記憶します。Android はリモートペインのヘッダー、iOS は時計アイコンから履歴を開きます。ローカルペインは選択したフォルダーを表示し、iOS は別の場所を選ぶまでアプリの Documents フォルダーを使います。

ファイル転送画面はシステムのライト／ダークテーマに従うため、Mobile SSH の他の画面と見た目がそろいます。

### セッションごとの開始フォルダー

両方とも tmux からファイル転送を開くと、**そのセッションとソケット**のリモートディレクトリを復元します。新しいセッションはホストでよく使う場所から試し、他の履歴やログインディレクトリに進みます。

記憶した場所がない、またはアクセスできない場合は次の利用可能な場所を試します。接続失敗はフォルダー不存在と混同せず報告します。更新だけでは訪問回数は増えません。

## ストレージアクセス

Mobile SSH はどちらのプラットフォームでも包括的なストレージ権限を求めません。

Android ではシステムのフォルダー選択ツールで **フォルダーを 1 つ** 許可し、ダウンロードはそこに書き込まれます — 他のすべてのアプリがすでに読める場所です。この許可はアプリを起動し直しても保持されます。

iOS は**自分のスマートフォン → ローカルフォルダーを選択**で「ファイル」内のフォルダーを許可します。対応する iCloud Drive や他の提供元も使え、再起動後も記憶します。**アプリのフォルダーを使用**で Mobile SSH の Documents に戻ります。選択先が使えない場合は再選択するか、明示的にアプリのフォルダーへ切り替えてください。ダウンロード先は勝手に変わりません。この端末のフォルダー権限はバックアップに含まれません。

iOS の書類・写真ピッカーは複数項目の取り込みにも対応します。同名なら**置き換え**・**両方保持**・**キャンセル**を選べます。既に同じ場所にあるファイルを取り込んでも壊しません。

秘密鍵のインポートはファイル転送とは別で、システムのファイル選択ツールを使います。

## ファイルをアップロードする

1. ローカルペインを開きます。
2. アップロードしたいファイルへ移動します。
3. アップロードを選びます。
4. リモートの保存先を確認します。
5. 進捗と完了は転送キューで確認します。

アップロードは保存された踏み台を含む、選択サーバーの SSH 経路に従います。切断した場合は再接続してやり直してください。

## ファイルをダウンロードする

1. リモートペインを開きます。
2. ダウンロードしたいファイルへ移動します。
3. ダウンロードを選びます。
4. ローカルの保存先を確認します。
5. 進捗と完了は転送キューで確認します。

大きなダウンロードは、可能なら安定したネットワークで行ってください。

## フォルダーをまるごとコピーする

アップロードとダウンロードは単一のファイルに限りません。フォルダーを選ぶと、Mobile SSH はサブツリー全体を双方向で — スマートフォンからリモートへ、リモートからスマートフォンへ — コピーします。まず保存先のディレクトリを作成し、続いて各ファイルをキューに入れます。読み取れないサブディレクトリがあっても残りのコピーは止まりません。Android では「Can't list directory」と表示される失敗行として報告され、iOS はスキップした対象を挙げずに続行します。

## リモートファイルの操作

選択したリモート項目に応じて、Mobile SSH は次のような操作を表示できます。

- **スマートフォンにコピー**でダウンロード。
- **サーバー上での** コピーまたは移動 — `cp -r`／`mv` がホスト側で実行され、データがスマートフォンを経由しません。
- 名前の変更。
- 削除。
- ファイルまたはディレクトリの作成。
- テキストファイルの編集。
- `.tar.gz` への圧縮。
- 権限 — モードと所有者の変更。フォルダー全体に適用するオプション付き。
- 別のアプリで開く。
- ファイルの詳細表示。

リモートファイルの詳細には、権限ビット、所有者、グループ、8 進数の権限値が含まれることがあります。別のプロセスやデプロイツールが管理するサーバーファイルを変更する前に、これらの詳細を確認してください。

ファイルサイズは二進接頭辞で表示されるため、隣のタブのターミナルで `ls -h` が出力する値と一致します。

## 並べ替えと最近のパス

各ペインは名前または日付で昇順・降順に並べ替えられます。Mobile SSH は選択したローカルおよびリモートの並べ替え方式を最近のパスとともにホストごとに保存するため、同じサーバーへの繰り返しの転送はなじみのある場所から始まります。

## 転送キュー

転送は状態ごとに並び、Android は待機中／失敗／成功、iOS は実行中／失敗／完了です。失敗には取得できた理由を表示します。iOS の現在の転送は実行中の先頭に置かれ、キャンセルできます。

iOS の待機中の転送は、別の場所を閲覧しても元のフォルダーを保持します。ダウンロードは一時領域で完了してから対象を置き換え、キャンセルや失敗では既存ファイルを残します。上書き承認後に対象が変わっていれば、置き換えずに停止します。

## ファイルをアプリの外へ取り出す

- **Android：** ダウンロードは許可したフォルダーに保存されるため、最初から他のすべてのアプリから見えます。**別のアプリで開く** は両方のペインにあり、リモートファイルはまずダウンロードされてから引き渡されます。
- **iOS：****別のアプリで開く**はローカル・リモート両方のファイルで使えます。リモートは先にダウンロードしてから共有シートを開きます。アプリのフォルダーは**この iPhone 内 → Mobile SSH**、外部フォルダーは「ファイル」の元の場所にあります。

## セッションにファイルを送る

両方とも他アプリから共有されたファイルを受け付け、端末に 📎 **ファイルを添付**を備えます。選択ホストの `~/.cache/mobile-ssh` にアップロードし、Enter を押さずにパスをプロンプトへ挿入できます。複数ファイルに対応します。

Android は実行中のセッションが共有先です。iOS のクリップは**写真ライブラリ**か**ファイル**を選べます。iOS 共有拡張は Mobile SSH が閉じていても保存した SSH サーバーへアップロードできますが、Eternal Terminal は選べません。未知のサーバーは先に本体アプリで身元を確認してください。

iOS 共有拡張のアップロード後は、パスをクリップボードへコピーし、そのサーバーの接続済みペインがアプリ内に現れたときに挿入するよう待機します。別ホストのペインには挿入しません。

## 実用的なヒント

- 個別のファイル移動には SFTP を使い、大きなディレクトリの同期にはサーバー上で `rsync` などのコマンドラインツールを使ってください。
- バックアップやデプロイのロールバック手段がない限り、稼働中の本番ファイルの編集は避けてください。
- アップロード後にファイルが表示されない場合は、リモートペインを更新するか、保存先パスを確認してください。
- Android のローカルペインが空なら**フォルダーを選択**を使います。iOS は保存したい場所に応じて**ローカルフォルダーを選択**、**アプリのフォルダーを使用**、取り込みピッカーを使います。
