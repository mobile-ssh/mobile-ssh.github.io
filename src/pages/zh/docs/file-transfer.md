# 文件传输

Mobile SSH 包含一个与活动 SSH 连接绑定的 SFTP 文件传输屏幕。它用于从手机或平板电脑进行快速的服务器维护：上传配置、下载日志、重命名远程文件或查看权限，而无需离开应用。

## 打开文件传输

1. 连接到 SSH 服务器。
2. 选择已连接的终端窗格。
3. 从终端工具栏打开 **Transfer**，或在当前屏幕支持时长按窗格标题。
4. 文件传输屏幕会打开，包含本地窗格和远程窗格。

如果没有活动的 SSH 会话，则无法打开文件传输。

## 本地与远程窗格

文件传输屏幕有两个浏览窗格：

- **本地窗格：** 手机存储。
- **远程窗格：** 通过 SFTP 访问的服务器文件。

应用会按主机记住最近的本地和远程路径。两个窗格的排序设置也会按主机记住。

## 存储访问

在限制直接浏览文件的 Android 版本上，Mobile SSH 可能会在本地窗格浏览手机文件之前请求存储访问权限。如果你跳过或拒绝此权限，远程浏览可能仍然有效，但本地上传和下载路径可能受限。

在 iOS 上，本地窗格使用应用自己的文档区域，你可以通过系统的文档选择器和照片选择器导入文件——包括对照片和文档的多选导入。无需单独的存储权限。

私钥导入与文件传输分开，使用系统文件选择器。

## 上传文件

1. 打开本地窗格。
2. 导航到你要上传的文件。
3. 选择上传。
4. 确认远程目标。
5. 在传输队列中查看进度和完成情况。

上传使用现有的 SSH/SFTP 连接。如果连接断开，请在重连后重试。

## 下载文件

1. 打开远程窗格。
2. 导航到你要下载的文件。
3. 选择下载。
4. 确认本地目标。
5. 在传输队列中查看进度和完成情况。

大文件下载应尽量在稳定的网络下进行。

## 复制整个文件夹

上传和下载不限于单个文件。选择一个文件夹，Mobile SSH 会在两个方向上复制整个子目录树——从手机到远程以及从远程到手机——先创建目标目录，再将每个文件加入队列。无法读取的子目录会被跳过并报告，而不会中断其余复制。

## 远程文件操作

根据所选的远程项目，Mobile SSH 可显示以下操作：

- 下载。
- 重命名。
- 删除。
- 创建文件或目录。
- 编辑文本文件。
- 查看文件详情。

远程文件详情可包含权限位、所有者、所属组和八进制权限值。在更改由其他进程或部署工具管理的服务器文件之前，请先查看这些详情。

## 排序与最近路径

每个窗格都可按名称或日期升序或降序排序。Mobile SSH 会按主机存储所选的本地和远程排序方式以及最近路径，因此对同一服务器的重复传输会从熟悉的位置开始。

## 传输队列

传输会排入队列并按状态显示。日志区域将排队、失败和成功的传输分开。当底层 SFTP 操作提供原因时，失败的传输会包含原因。

## 实用提示

- 使用 SFTP 进行有针对性的文件移动；对于大型目录同步，请在服务器上使用 `rsync` 等命令行工具。
- 除非你有备份或部署回滚路径，否则避免编辑正在运行的生产文件。
- 如果上传后文件未出现，请刷新远程窗格或核实目标路径。
- 如果 Android 存储访问阻止本地浏览，请在 Android Settings 中授予权限，然后重新打开文件传输。在 iOS 上，请改用选择器将文件添加到本地窗格。
