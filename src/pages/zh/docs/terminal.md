# 终端

Mobile SSH 终端专为手机和平板操作而设计。它结合了终端画布、额外按键行、多会话窗格、滚动处理和重连行为。

## 终端基础

- 终端采用 xterm 风格的行为，支持颜色和光标键处理。
- 回滚缓冲区最多保留 5000 行。
- 输入前先点按窗格以选中它。
- 在终端窗格上双指捏合可更改文字大小。手势稳定后，Mobile SSH 会调整远程 PTY 的大小。
- 双击窗格（或使用其展开按钮）进入全屏模式。在 Android 上使用返回键，或在 iOS 上使用收起按钮，回到网格。

## 多会话网格

Mobile SSH 最多可同时运行八个 SSH 会话。每个会话以窗格形式显示在终端网格中。窗格标题显示当前目标或标题。点按窗格以选中它，或使用 **+ Add Session** 开始另一个连接。

关闭窗格会断开该 SSH 会话。返回起始屏幕时，活动会话仍可通过 **Active Sessions** 使用。

## 额外按键行

在 Android 和 iOS 上，额外按键行都显示在屏幕键盘上方，提供在触摸键盘上不便输入的终端按键：

- `ESC`
- `TAB`
- `CTRL`
- `Shift`
- 方向键
- `HOME`
- `END`
- `PGUP`
- `PGDN`
- 键盘开关

`CTRL` 和 `Shift` 作为粘滞修饰键作用于下一次兼容输入。例如，点按 `CTRL`，再输入 `C`，即可发送 Ctrl-C。

## 键盘行为

终端通过原生直通方式连接屏幕键盘：你每输入一个字符都会立即发送到远程 shell，自动更正与预测建议均已关闭，因此键盘绝不会在输入到达 shell 之前改写它。这让 Vim、tmux、htop、less、使用特殊组合键的 shell 以及远程密码提示都保持可预测——没有需要关闭的建议缓冲。

- **点按终端显示键盘：** 启用后，点按终端会请求系统显示屏幕键盘。

软键盘语音听写仍然可用：听写出的文本会像其他输入一样直接提交到 shell。

## 硬件键盘

外接与 Bluetooth 键盘可在 Android 和 iOS 上直接驱动终端。除普通字符外，Mobile SSH 还映射方向键、`Home`/`End`、`PgUp`/`PgDn`、`Insert`、`Delete`、`Esc`、功能键 `F1`–`F12`、`Ctrl`+按键以及 `Alt`/`Option` 作为 Meta 的组合键，还有 `Shift`+`Tab`。这些修饰键可与额外按键行的粘滞修饰键组合使用。

## 粘贴

向请求粘贴的程序（bash、Vim 以及其他支持括号粘贴的应用）粘贴时，内容会被括号粘贴标记包裹，因此多行剪贴板内容会作为文本插入，而不会被逐行自动执行。只有真正的粘贴才会被包裹；输入和听写的文本不受影响。

## 选择、复制、分享

在终端内长按可进入选择模式。选择工具栏提供三个操作：

- **复制** —— 将所选文本放入系统剪贴板。
- **分享** —— 将所选文本传给系统分享面板（邮件、笔记、消息等）。
- **全选** —— 将选择扩展到整个可见终端缓冲区，然后复制或分享。

## 滚动

Mobile SSH 根据终端状态路由滚动手势：

- 在正常 shell 输出中，滑动会滚动本地回滚缓冲区。
- 在鼠标模式的终端应用中，滚动会发送鼠标滚轮转义序列。
- 在没有鼠标模式的备用屏幕应用中（如许多 tmux 会话），滚动会进入 tmux 复制模式并发送逐行滚动命令。

如果你在回滚状态下输入，Mobile SSH 会返回到实时终端视图。

## tmux 行为

Mobile SSH 会观察发出的 tmux attach 和新建会话命令，例如：

```bash
tmux attach -t work
tmux a -t work
tmux new -A -s work
```

当你在 tmux 中时连接断开，应用可记住该服务器最后的 tmux 会话名称，并在重连后尝试重新挂接。如果未观察到明确的会话名称，但应用知道你处于备用屏幕的类 tmux 会话中，它可能会尝试通用的 `tmux attach`。

此行为为尽力而为。如果远程 tmux 会话不再存在，远程 shell 仍然可用。

## Agent alerts

Mobile SSH 可监控当前会话的终端输出，识别表明远程代理正在等待输入的模式。当检测到匹配时——例如 Claude Code 或 Codex 暂停等待提示——应用会发送带有可选声音和振动的通知。

配置方法：

1. 从起始屏幕打开 **Settings**。
2. 启用 **Agent alerts**。
3. 选择通知声音和振动模式。

提醒通过当前活跃的音频输出播放，包括耳机，因此你在看视频或手机锁屏时也能听到。即使 Mobile SSH 在后台运行，通知也会正常显示。

Agent alert 模式与可见的终端输出进行匹配。如果你的远程工具输出了可识别的提示行（用户名、`?`、带括号的问题），应用可能会自动捕获。如果提醒触发过于频繁或完全不触发，请在 Settings 中调整灵敏度。

## 全屏终端程序

对于 Vim、less、htop、ncurses 工具和 tmux 窗格等程序：

- 输入会直接传递给程序——没有自动更正或建议缓冲进行干扰。
- 使用额外按键行输入 `ESC`、方向键、`PGUP` 和 `PGDN`。
- 如果文字太小，使用捏合缩放，然后稍等片刻让远程终端大小稳定。
