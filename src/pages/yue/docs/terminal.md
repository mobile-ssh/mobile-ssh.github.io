# 終端機

Mobile SSH 終端機係為手機同平板操作而設計。佢結合咗終端機畫布、額外按鍵列、多工作階段窗格、捲動處理同重新連線行為。

## 終端機基礎

- 終端機採用 xterm 風格行為，支援顏色同游標鍵處理。
- 捲動緩衝區最多保留 5000 行。
- 輸入之前先撳窗格去選取佢。
- 喺終端機窗格上面用兩指捏合可以更改文字大細。手勢穩定之後，Mobile SSH 會調整遠端 PTY 嘅大細。
- 雙撳窗格（或者用佢嘅展開控制項）進入全螢幕模式。喺 Android 用返回鍵，喺 iOS 用收合控制項，返去格網。

## 多工作階段格網

Mobile SSH 最多可以同時執行八個 SSH 工作階段。每個工作階段以窗格形式顯示喺終端機格網。窗格標題顯示目前目標或標題。撳窗格去選取佢，或者用 **+ Add Session** 開始另一個連線。

關閉窗格會中斷嗰個 SSH 工作階段。返起始畫面嗰陣，使用中工作階段仍然可以透過 **Active Sessions** 使用。

## 額外按鍵列

喺 Android 同 iOS 上面，額外按鍵列都會顯示喺螢幕鍵盤上面，提供喺觸控鍵盤上唔方便輸入嘅終端機按鍵：

- `ESC`
- `TAB`
- `CTRL`
- `Shift`
- 方向鍵
- `HOME`
- `END`
- `PGUP`
- `PGDN`
- 鍵盤切換

`CTRL` 同 `Shift` 會作為黏性修飾鍵作用於下一次相容輸入。例如，撳 `CTRL`，再輸入 `C`，就會傳送 Ctrl-C。

## 鍵盤行為

終端機同螢幕鍵盤採用原生直通連接：你打字嗰陣，每個字元即刻傳去遠端 shell，自動更正同預測建議都關咗，所以鍵盤永遠唔會喺輸入到達 shell 之前改寫佢。噉樣令 Vim、tmux、htop、less、用特殊組合鍵嘅 shell 同遠端密碼提示都保持可預期 —— 冇任何建議緩衝需要關閉。

- **撳終端機顯示鍵盤：** 啟用之後，撳終端機會要求系統顯示螢幕鍵盤。

螢幕鍵盤嘅語音聽寫照樣用得：聽寫嘅文字會好似其他輸入一樣，直接送入 shell。

## 硬件鍵盤

外接同 Bluetooth 鍵盤喺 Android 同 iOS 上面都可以直接操控終端機。除咗普通字元，Mobile SSH 仲對應方向鍵、`Home`/`End`、`PgUp`/`PgDn`、`Insert`、`Delete`、`Esc`、功能鍵 `F1`–`F12`、`Ctrl`+按鍵同 `Alt`/`Option` 作為 Meta 嘅組合鍵，以及 `Shift`+`Tab`。修飾鍵會同額外按鍵列嘅黏性修飾鍵一齊組合。

## 貼上

當你貼上落一個有要求嘅程式（bash、Vim 同其他支援 bracketed-paste 嘅應用程式），內容會用括號貼上標記包住，所以多行剪貼簿內容會以文字方式插入，而唔會逐行被自動執行。只有真正嘅貼上先會咁包住；輸入同聽寫嘅文字唔會受影響。

## 選取、複製、分享

喺終端機入面長撳可以選取手指下面嗰個詞語，再拉動控制點去調整範圍。選取工具列提供三個操作：

- **複製** —— 將所選文字放入系統剪貼簿。複製之後選取仍然保持 highlight，方便你分享、重新複製或者延伸範圍。
- **分享** —— 將所選文字傳俾系統分享面板（電郵、筆記、訊息等）。
- **全選** —— 將選取擴展到整個可見終端機緩衝區，然後複製或分享。

## 喺終端機入面尋找

搜索成個終端機緩衝區 —— 包括回滾緩衝同可見畫面 —— 並喺各個匹配之間跳轉。喺終端機控制項打開搜索，輸入查詢字串，再逐個匹配去睇。Android 同 iOS 都用得。

## 色彩、斜體同遠端剪貼簿

- 終端機會顯示 **24-bit 真彩色** 同 **斜體**，令主題化嘅提示符、語法高亮同 TUI 睇落同桌面上一樣。
- **OSC 52 剪貼簿：** 當遠端程式複製文字（tmux `set-clipboard`、Vim/Neovim 嘅 OSC 52 yank），佢會落到你電話嘅剪貼簿 —— 咁你就可以喺伺服器度複製，再貼到本機 App。
- 喺 Android 同 iOS 上，寬 CJK、emoji 同組合字元（字素叢集同零寬連接符）都會正確量度同繪製，而內置嘅 **Nerd Font** 仲會顯示 powerline、starship、devicon 同 Material Design 圖示字形 —— 系統字型本來會將佢哋顯示成空白方格。

## Shell 整合同內嵌圖片

- **Shell 整合（OSC 133）：** 當你嘅 shell 送出 OSC 133 提示符標記時，Mobile SSH 可以喺各個提示符之間跳轉、複製單一指令嘅輸出，並喺長時間指令完成時提示你。Android 同 iOS 都用得。
- **內嵌圖片：** 用 Kitty graphics protocol 嘅程式會直接喺終端機畫出圖片，Android 同 iOS 都得。

## 外觀同按鍵

喺 Android 同 iOS，Settings 可以俾你自訂終端機：

- **字型：** 揀系統等寬字型、JetBrains Mono 或者 Source Code Pro。
- **配色：** Default、Solarized Dark 或 Light、Gruvbox、Dracula，或者 Nord —— 即時套用到開住嘅面板。
- **附加按鍵列：** 新增、移除、重新排序同隱藏按鍵，自訂你自己嘅跳脫序列按鍵，並重設做預設，仲有即時預覽。
- **回滾大細：** 設定終端機保留幾多行。

## 捲動

Mobile SSH 會根據終端機狀態路由捲動手勢：

- 喺正常 shell 輸出，滑動會捲動本機捲動緩衝區。
- 喺滑鼠模式嘅終端機應用程式，捲動會傳送滑鼠滾輪逸出序列。
- 喺冇滑鼠模式嘅備用畫面應用程式（例如好多 tmux 工作階段），捲動會進入 tmux 複製模式並傳送逐行捲動指令。

如果你喺向後捲動嘅狀態下輸入，Mobile SSH 會返去即時終端機檢視。

## tmux 行為

Mobile SSH 會觀察送出嘅 tmux attach 同新工作階段指令，例如：

```bash
tmux attach -t work
tmux a -t work
tmux new -A -s work
```

當你喺 tmux 入面時連線中斷，應用程式可以記住嗰部伺服器最後嘅 tmux 工作階段名稱，並喺重新連線之後嘗試重新附加。如果冇觀察到明確嘅工作階段名稱，但應用程式知道你曾經喺備用畫面嘅類 tmux 工作階段，佢可能會嘗試通用嘅 `tmux attach`。

呢個行為係盡力而為。如果遠端 tmux 工作階段已經唔存在，遠端 shell 仍然可用。

## Agent alerts

Mobile SSH 可以監察使用中工作階段嘅終端機輸出，尋找表示遠端代理正在等待輸入嘅模式。當偵測到匹配——例如 Claude Code 或 Codex 暫停等待提示——應用程式會發出通知，並可選擇聲音同震動。

設定方法：

1. 喺起始畫面開啟 **Settings**。
2. 啟用 **Agent alerts**。
3. 選擇通知聲音同震動模式。

提示音會透過當時使用緊嘅音頻輸出播放，包括耳機，所以你睇緊片或者鎖定手機嗰陣都聽得到。即使 Mobile SSH 喺背景執行，通知都會顯示。

Agent alert 模式係對照可見終端機輸出進行比對。如果你嘅遠端工具輸出咗可識別嘅提示行（用戶名、`?`、方括號問題），應用程式可能會自動偵測到。如果提示過於頻繁或者完全唔觸發，可以喺 Settings 調整靈敏度。

## 全螢幕終端機程式

對於 Vim、less、htop、ncurses 工具同 tmux 窗格等程式：

- 輸入會直接傳去程式 —— 冇自動更正或者建議緩衝去干擾。
- 用額外按鍵列輸入 `ESC`、方向鍵、`PGUP` 同 `PGDN`。
- 如果文字太細，用捏合縮放，然後等一陣等遠端終端機大細穩定。
