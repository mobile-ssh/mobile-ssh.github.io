# 檔案傳輸

Mobile SSH 包含一個同使用中 SSH 連線綁定嘅 SFTP 檔案傳輸畫面。佢用嚟由你嘅手機或平板做快速嘅伺服器維護：上載設定、下載日誌、重新命名遠端檔案，或者檢視權限，而唔使離開應用程式。

## 開啟檔案傳輸

1. 連線到 SSH 伺服器。
2. 選取已連線嘅終端機窗格。
3. 由終端機工具列開啟 **Transfer**，或者喺目前畫面支援時長撳窗格標題。
4. 檔案傳輸畫面會開啟，包含本機窗格同遠端窗格。

如果冇使用中嘅 SSH 工作階段，就唔可以開啟檔案傳輸。

## 本機同遠端窗格

檔案傳輸畫面有兩個瀏覽窗格：

- **本機窗格：** 手機儲存空間。
- **遠端窗格：** 透過 SFTP 嘅伺服器檔案。

應用程式按主機記住最近遠端路徑同排序。Android 喺遠端窗格標題開最近路徑，iOS 用時鐘圖示。本機窗格顯示你揀嘅資料夾；iOS 未揀其他位置之前用應用程式 Documents 資料夾。

檔案傳輸畫面會跟隨你嘅系統淺色或深色主題，所以同 Mobile SSH 其餘部分一致。

### 每個工作階段開喺邊度

兩個平台由 tmux 開檔案傳輸時，都會還原**嗰個工作階段同 socket**記住嘅遠端目錄。新工作階段先試主機常用目錄，再試其他記錄或登入目錄。

記住嘅目錄唔見咗或者入唔到，瀏覽器會試下一個可用位置。連線失敗會顯示錯誤，唔會當資料夾唔存在。重新整理唔會增加目錄造訪次數。

## 儲存空間存取

Mobile SSH 喺兩個平台都唔會攞全面嘅儲存權限。

喺 Android，你用系統嘅資料夾選擇器授權**一個資料夾**，下載嘅嘢就會寫入嗰度 —— 一個其他 App 本身已經讀得到嘅位置。呢個授權喺重開應用程式之後都仲喺度。

iOS 嘅**我的手機 → 選擇本機資料夾**可以授權讀寫「檔案」入面嘅資料夾，包括支援嘅 iCloud Drive 同其他檔案供應商。重開應用程式都會記住。**使用應用程式資料夾**返回 Mobile SSH 嘅 Documents。所選資料夾用唔到時，要重新揀或者明確轉返應用程式資料夾；下載唔會暗中轉去第二度。備份唔包括呢部裝置嘅資料夾權限。

iOS 文件同相片選擇器亦支援一次匯入多項。撞檔名可以揀**取代**、**保留兩者**或者**取消**。匯入已經喺目的地嘅檔案唔會改動佢。

私鑰匯入同檔案傳輸係分開嘅，用系統檔案選擇器。

## 上載檔案

1. 開啟本機窗格。
2. 瀏覽到你想上載嘅檔案。
3. 揀上載。
4. 確認遠端目標。
5. 喺傳輸佇列查看進度同完成情況。

上載跟住所選伺服器嘅 SSH 路由，包括儲存咗嘅跳板機。斷線後重連再試。

## 下載檔案

1. 開啟遠端窗格。
2. 瀏覽到你想下載嘅檔案。
3. 揀下載。
4. 確認本機目標。
5. 喺傳輸佇列查看進度同完成情況。

大型下載盡可能喺穩定嘅網絡進行。

## 複製成個資料夾

上載同下載唔止限於單一檔案。揀一個資料夾，Mobile SSH 就會喺兩個方向 —— 手機去遠端同遠端去手機 —— 複製成個子樹，先建立目標目錄，再將每個檔案排入佇列。讀唔到嘅子目錄唔會令其餘嘅複製停低；喺 Android，佢會以一行寫住「Can't list directory」嘅失敗紀錄報出嚟，而 iOS 就會繼續做落去，唔會列出佢略過咗啲乜。

## 遠端檔案操作

根據所選嘅遠端項目，Mobile SSH 可以顯示以下操作：

- 用**複製到手機**下載。
- 喺**伺服器上面**複製或者移動 —— `cp -r` / `mv` 喺主機上面行，啲位元組唔使經過你部電話。
- 重新命名。
- 刪除。
- 建立檔案或目錄。
- 編輯文字檔案。
- 壓縮做 `.tar.gz`。
- 權限 —— 更改模式同擁有者，仲可以選擇套用去成個資料夾。
- 用另一個應用程式開啟。
- 檢視檔案詳情。

遠端檔案詳情可以包含權限位元、擁有者、群組同八進位權限值。喺更改由其他程序或部署工具管理嘅伺服器檔案之前，請先查看呢啲詳情。

檔案大細以二進位單位顯示，所以同你隔籬個分頁終端機入面 `ls -h` 印出嚟嘅一樣。

## 排序同最近路徑

每個窗格都可以按名稱或日期升序或降序排序。Mobile SSH 會按主機儲存所選嘅本機同遠端排序方式以及最近路徑，所以對同一部伺服器嘅重複傳輸會由熟悉嘅位置開始。

## 傳輸佇列

傳輸會排隊並按狀態顯示：Android 係排隊中／失敗／成功，iOS 係進行中／失敗／完成。失敗項目顯示可用嘅錯誤原因。iOS 目前傳輸放喺「進行中」最頂，亦可取消。

iOS 排隊傳輸保留原本資料夾，就算你瀏覽咗第二度都唔變。下載先寫入暫存位置，完成先取代目標；取消或失敗會保留原有檔案。如果批准覆寫之後目標有變，應用程式會停低，唔會蓋過新內容。

## 點樣將檔案由應用程式攞出嚟

- **Android：** 下載嘅嘢會落喺你授權嗰個資料夾，所以其他 App 已經睇得到。兩個窗格都有 **Open in another app**；遠端檔案會先下載，再交俾另一個 App。
- **iOS：**本機同遠端檔案都有**用其他應用程式開啟**。遠端檔案先下載，再開分享面板。應用程式資料夾顯示喺**我的 iPhone → Mobile SSH**；外部資料夾留返喺「檔案」原本位置。

## 將檔案送入工作階段

兩個平台都接收其他應用程式分享嘅檔案，終端亦有 📎 **附加檔案**。檔案上載到所選主機嘅 `~/.cache/mobile-ssh`，路徑可插入提示符但唔會按 Enter。支援多個檔案。

Android 分享去執行緊嘅工作階段。iOS 萬字夾提供**相片圖庫**或者**檔案**。就算 Mobile SSH 關咗，iOS 分享擴充亦可以上載去儲存咗嘅 SSH 伺服器，但唔提供 Eternal Terminal 設定。未知伺服器要先喺主應用程式驗證身份。

iOS 分享擴充上載後，路徑會複製去剪貼簿並排隊，等應用程式有返嗰部伺服器嘅已連線窗格先插入。唔會插入連住其他主機嘅窗格。

## 實用提示

- 用 SFTP 做有針對性嘅檔案搬移；對於大型目錄同步，喺伺服器上用 `rsync` 等命令列工具。
- 除非你有備份或部署還原途徑，否則避免編輯執行緊嘅生產檔案。
- 如果上載之後檔案冇出現，請重新整理遠端窗格或核實目標路徑。
- Android 本機窗格空白時用**選擇資料夾**。iOS 按想存放嘅位置，揀**選擇本機資料夾**、**使用應用程式資料夾**或者匯入選擇器。
