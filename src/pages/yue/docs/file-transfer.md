# 檔案傳輸

Mobile SSH 包含一個同使用中 SSH 連線綁定嘅 SFTP 檔案傳輸畫面。佢用嚟由你嘅手機或平板做快速嘅伺服器維護：上載設定、下載日誌、重新命名遠端檔案，或者檢視權限，而唔使離開應用程式。

## 開啟檔案傳輸

1. 連線到 SSH 伺服器。
2. 選取已連線嘅終端機窗格。
3. 由終端機工具列開啟 **Transfer**，或者喺目前畫面支援時長撳窗格標題。
4. 檔案傳輸畫面會開啟，包含本機窗格同遠端窗格。

如果冇使用中嘅 SSH 工作階段，就唔可以開啟檔案傳輸。

## 本機同遠端窗格

檔案傳輸畫面有兩個瀏覽窗格：

- **本機窗格：** 手機儲存空間。
- **遠端窗格：** 透過 SFTP 嘅伺服器檔案。

應用程式會按主機記住最近嘅本機同遠端路徑。兩個窗格嘅排序設定都會按主機記住。

## 儲存空間存取

喺限制直接瀏覽檔案嘅 Android 版本，Mobile SSH 可能會喺本機窗格瀏覽手機檔案之前要求儲存權限。如果你略過或拒絕呢個權限，遠端瀏覽可能仍然有效，但本機上載同下載路徑可能受限。

喺 iOS，本機窗格用嘅係應用程式自己嘅文件區域，你可以透過系統嘅文件同相片選擇器將檔案帶入——包括多選匯入相片同文件。唔使另外嘅儲存權限。

私鑰匯入同檔案傳輸係分開嘅，用系統檔案選擇器。

## 上載檔案

1. 開啟本機窗格。
2. 瀏覽到你想上載嘅檔案。
3. 揀上載。
4. 確認遠端目標。
5. 喺傳輸佇列查看進度同完成情況。

上載用現有嘅 SSH/SFTP 連線。如果連線中斷，喺重新連線之後再試。

## 下載檔案

1. 開啟遠端窗格。
2. 瀏覽到你想下載嘅檔案。
3. 揀下載。
4. 確認本機目標。
5. 喺傳輸佇列查看進度同完成情況。

大型下載盡可能喺穩定嘅網絡進行。

## 複製成個資料夾

上載同下載唔止限於單一檔案。揀一個資料夾，Mobile SSH 就會喺兩個方向 —— 手機去遠端同遠端去手機 —— 複製成個子樹，先建立目標目錄，再將每個檔案排入佇列。讀唔到嘅子目錄會被略過並記錄下嚟，但唔會令其餘嘅複製停低。

## 遠端檔案操作

根據所選嘅遠端項目，Mobile SSH 可以顯示以下操作：

- 下載。
- 重新命名。
- 刪除。
- 建立檔案或目錄。
- 編輯文字檔案。
- 檢視檔案詳情。

遠端檔案詳情可以包含權限位元、擁有者、群組同八進位權限值。喺更改由其他程序或部署工具管理嘅伺服器檔案之前，請先查看呢啲詳情。

## 排序同最近路徑

每個窗格都可以按名稱或日期升序或降序排序。Mobile SSH 會按主機儲存所選嘅本機同遠端排序方式以及最近路徑，所以對同一部伺服器嘅重複傳輸會由熟悉嘅位置開始。

## 傳輸佇列

傳輸會排入佇列並按狀態顯示。日誌區域將佇列中、失敗同成功嘅傳輸分開。當底層 SFTP 操作提供原因時，失敗嘅傳輸會包含原因。

## 實用提示

- 用 SFTP 做有針對性嘅檔案搬移；對於大型目錄同步，喺伺服器上用 `rsync` 等命令列工具。
- 除非你有備份或部署回滾途徑，否則避免編輯執行緊嘅生產檔案。
- 如果上載之後檔案冇出現，請重新整理遠端窗格或核實目標路徑。
- 如果 Android 儲存權限阻止本機瀏覽，請喺 Android 設定授予權限，然後重新開啟檔案傳輸。喺 iOS，就改用選擇器將檔案加入本機窗格。
