# 檔案傳輸

Mobile SSH 包含一個同使用中 SSH 連線綁定嘅 SFTP 檔案傳輸畫面。佢用嚟由你嘅手機或平板做快速嘅伺服器維護：上載設定、下載日誌、重新命名遠端檔案，或者檢視權限，而唔使離開應用程式。

## 開啟檔案傳輸

1. 連線到 SSH 伺服器。
2. 選取已連線嘅終端機窗格。
3. 由終端機工具列開啟 **Transfer**，或者喺目前畫面支援時長撳窗格標題。
4. 檔案傳輸畫面會開啟，包含本機窗格同遠端窗格。

如果冇使用中嘅 SSH 工作階段，就唔可以開啟檔案傳輸。

## 本機同遠端窗格

檔案傳輸畫面有兩個瀏覽窗格：

- **本機窗格：** 手機儲存空間。
- **遠端窗格：** 透過 SFTP 嘅伺服器檔案。

應用程式會按主機記住最近十個遠端路徑 —— 喺 Android 由遠端窗格嘅標題打開佢哋，喺 iOS 就撳個時鐘圖示。兩個窗格嘅排序設定都會按主機記住。本機路徑就冇歷史：喺 Android，本機窗格就係你授權咗嗰個資料夾，喺 iOS 就係應用程式自己嘅文件區域。

檔案傳輸畫面會跟隨你嘅系統淺色或深色主題，所以同 Mobile SSH 其餘部分一致。

### 每個工作階段由邊度開始（Android）

由一個附加咗 tmux 工作階段嘅窗格開啟檔案傳輸，遠端窗格會返返去**嗰個工作階段**上次做嘢嘅位置，而窗格標題會寫低個工作階段名。如果係你未由佢開過檔案傳輸嘅工作階段，就會由你喺嗰部主機最常用嘅目錄開始，跟住係嗰部主機最後用嘅目錄，再跟住係你嘅家目錄。

如果記住咗嘅目錄之後被刪咗，應用程式會沿住呢張清單一路試落去，直到有一個真係列到內容為止，而唔會就噉留你喺一個錯誤畫面 —— 而且佢唔會將個壞咗嘅路徑寫返落去。喺 iOS，每部主機記一個遠端目錄。

## 儲存空間存取

Mobile SSH 喺兩個平台都唔會攞全面嘅儲存權限。

喺 Android，你用系統嘅資料夾選擇器授權**一個資料夾**，下載嘅嘢就會寫入嗰度 —— 一個其他 App 本身已經讀得到嘅位置。呢個授權喺重開應用程式之後都仲喺度。

喺 iOS，本機窗格就係應用程式嘅文件區域，檔案經系統嘅文件同相片選擇器帶入。

喺 iOS，本機窗格用嘅係應用程式自己嘅文件區域，你可以透過系統嘅文件同相片選擇器將檔案帶入——包括多選匯入相片同文件。唔使另外嘅儲存權限。

私鑰匯入同檔案傳輸係分開嘅，用系統檔案選擇器。

## 上載檔案

1. 開啟本機窗格。
2. 瀏覽到你想上載嘅檔案。
3. 揀上載。
4. 確認遠端目標。
5. 喺傳輸佇列查看進度同完成情況。

上載用現有嘅 SSH/SFTP 連線。如果連線中斷，喺重新連線之後再試。

## 下載檔案

1. 開啟遠端窗格。
2. 瀏覽到你想下載嘅檔案。
3. 揀下載。
4. 確認本機目標。
5. 喺傳輸佇列查看進度同完成情況。

大型下載盡可能喺穩定嘅網絡進行。

## 複製成個資料夾

上載同下載唔止限於單一檔案。揀一個資料夾，Mobile SSH 就會喺兩個方向 —— 手機去遠端同遠端去手機 —— 複製成個子樹，先建立目標目錄，再將每個檔案排入佇列。讀唔到嘅子目錄唔會令其餘嘅複製停低；喺 Android，佢會以一行寫住「Can't list directory」嘅失敗紀錄報出嚟，而 iOS 就會繼續做落去，唔會列出佢略過咗啲乜。

## 遠端檔案操作

根據所選嘅遠端項目，Mobile SSH 可以顯示以下操作：

- 下載，或者喺 Android 叫 **Copy to phone**。
- 喺**伺服器上面**複製或者移動 —— `cp -r` / `mv` 喺主機上面行，啲位元組唔使經過你部電話。
- 重新命名。
- 刪除。
- 建立檔案或目錄。
- 編輯文字檔案。
- 壓縮做 `.tar.gz`。
- 權限 —— 更改模式同擁有者，仲可以選擇套用去成個資料夾。
- 用另一個應用程式開啟。
- 檢視檔案詳情。

遠端檔案詳情可以包含權限位元、擁有者、群組同八進位權限值。喺更改由其他程序或部署工具管理嘅伺服器檔案之前，請先查看呢啲詳情。

檔案大細以二進位單位顯示，所以同你隔籬個分頁終端機入面 `ls -h` 印出嚟嘅一樣。

## 排序同最近路徑

每個窗格都可以按名稱或日期升序或降序排序。Mobile SSH 會按主機儲存所選嘅本機同遠端排序方式以及最近路徑，所以對同一部伺服器嘅重複傳輸會由熟悉嘅位置開始。

## 傳輸佇列

傳輸會排入佇列並按狀態顯示，而個日誌會列出每一次傳輸，仲可以捲動 —— Android 分做 Queued / Failed / Successful 分頁，iOS 就分做 Active / Failed / Done。當底層 SFTP 操作提供原因時，失敗嘅傳輸會包含原因。喺 iOS，正傳輸緊嗰個檔案會留喺 Active 分頁最頂，而且傳輸途中都可以取消一行。

## 點樣將檔案由應用程式攞出嚟

- **Android：** 下載嘅嘢會落喺你授權嗰個資料夾，所以其他 App 已經睇得到。兩個窗格都有 **Open in another app**；遠端檔案會先下載，再交俾另一個 App。
- **iOS：** Mobile SSH 會喺「檔案」App 嘅 **On My iPhone** 底下出現，所以「我嘅電話」窗格入面嘅嘢，喺郵件、選擇器同其他 App 都攞得到。長撳一個已下載嘅檔案，揀 **Open in another app**，就可以交俾另一個 App、用 AirDrop 傳送，或者存去第二度。

## 將檔案送入工作階段（Android）

Android 接受由任何其他 App 分享入嚟嘅檔案：分享去 Mobile SSH，個檔案就會上載到嗰個窗格所在主機嘅 `~/.cache/mobile-ssh`，而佢嘅遠端路徑會幫你打咗喺提示符度，等你即刻用得。終端機工具列上面嘅 📎 掣由系統檔案選擇器做同樣嘅嘢，兩者都可以一次過收幾個檔案。

喺 iOS，用 ＋ 掣將檔案帶入本機窗格，再由嗰度上載。

## 實用提示

- 用 SFTP 做有針對性嘅檔案搬移；對於大型目錄同步，喺伺服器上用 `rsync` 等命令列工具。
- 除非你有備份或部署回滾途徑，否則避免編輯執行緊嘅生產檔案。
- 如果上載之後檔案冇出現，請重新整理遠端窗格或核實目標路徑。
- 如果 Android 嘅本機窗格係空嘅，用 **Pick folder** 揀一個資料夾 —— 應用程式淨係有你授權嗰個資料夾嘅存取權。喺 iOS，就改用選擇器將檔案加入本機窗格。
