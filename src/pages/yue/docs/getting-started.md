# 開始使用

Mobile SSH 係一款支援 Android 同 iOS 嘅 SSH 用戶端，用嚟連線你自己嘅 Linux、Unix、網絡、IoT 或開發伺服器。你提供伺服器位址同憑證，應用程式就會開一個互動式 SSH 終端機。

## 需求

- Android 8.0 或更新版本，或者 iOS 16 或更新版本（iPhone 或 iPad）。
- 裝置可以連到你嘅 SSH 伺服器嘅網絡。
- SSH 伺服器嘅主機名稱或 IP 位址、連接埠、用戶名，以及密碼或私鑰。
- 喺 Android，如果你想用帶本機手機檔案瀏覽器嘅 SFTP 檔案傳輸，就需要儲存權限；iOS 就改用系統嘅檔案同相片選擇器。

## 安裝應用程式

- **Android：** 喺 Google Play 安裝 Mobile SSH。
- **iOS：** iOS 應用程式以公開測試版形式喺 TestFlight 提供。安裝 Apple 嘅 TestFlight 應用程式，然後喺網站主頁開啟 Mobile SSH 邀請連結，就可以安裝同接收更新。

## 連線到伺服器

1. 開啟 Mobile SSH。
2. 撳 **+ Add Session** 搜尋已儲存嘅伺服器，或者喺嗰個畫面新增伺服器。
3. 如果係新增伺服器，填入主機、連接埠、用戶名同驗證資料。
4. 撳伺服器去開啟終端機工作階段。
5. 喺起始畫面用 **Active Sessions** 返去仍然執行緊嘅工作階段。

預設 SSH 連接埠係 `22`。如果你嘅伺服器用其他連接埠，喺伺服器設定檔入面填返個連接埠。

## 儲存伺服器

已儲存伺服器會保留連線目標同可選嘅通道設定。一個已儲存伺服器可以包含：

- 主機名稱或 IP 位址。
- SSH 連接埠。
- 用戶名。
- 密碼或私鑰資料。
- 可選嘅本機連接埠轉發規則。

對你經常存取嘅主機用已儲存伺服器。如果某個已儲存伺服器指向同你目前使用中工作階段唔同嘅主機，Mobile SSH 會為所選目標開一個新連線。

## 儲存憑證

**Credentials** 畫面會儲存可重用嘅用戶名/密碼或用戶名/私鑰記錄。你可以喺伺服器設定對話框揀返已儲存嘅憑證，咁就唔使為每部主機重複輸入相同嘅登入資料。

憑證記錄儲存喺裝置本機——喺 iOS，機密資料會保存喺系統 Keychain 入面。如果你儲存密碼、密鑰口令或私鑰，請用螢幕鎖保護部裝置。

## 使用私鑰

Mobile SSH 支援貼上私鑰，同埋透過系統檔案選擇器匯入金鑰。喺 Android，應用程式支援 Ed25519、RSA、ECDSA 同 DSA 金鑰；喺 iOS 就支援 Ed25519 同 ECDSA（P-256/384/521）金鑰。

使用私鑰嘅方法：

1. 開啟 **Credentials** 或伺服器編輯對話框。
2. 貼上私鑰文字，或者揀 **Import from file**。
3. 如果金鑰已加密，喺密碼/口令欄位輸入金鑰口令。
4. 儲存憑證或伺服器。

私鑰匯入用系統檔案選擇器揀金鑰檔案。喺 Android，檔案傳輸用另一個本機檔案瀏覽器，喺較新嘅 Android 版本可能會要求更廣嘅儲存權限；喺 iOS，檔案就經系統嘅文件同相片選擇器帶入。

## 最近工作階段

起始畫面會顯示最近工作階段。最近工作階段可以重新連線到同一組伺服器。如果上一個工作階段仍然使用緊，Mobile SSH 會返去嗰個，而唔係開一個重複嘅連線。

## 搜尋已儲存伺服器

喺 **Saved Servers** 頁面撳搜尋欄，可以按名稱或主機篩選。**+ Add Session** 畫面都會開啟搜尋，方便你一步搵到並連線已儲存嘅伺服器。

## 使用中工作階段

當有工作階段執行緊，起始畫面會顯示帶計數嘅 **Active Sessions**。撳佢返去終端機格網。持續通知亦會列出使用中嘅主機——撳通知入面嘅主機可以直接跳去嗰個終端機。

返起始畫面唔會中斷使用中嘅 SSH 工作階段；關閉窗格或結束終端機活動先會中斷佢哋。

## 最先有用嘅設定

喺起始畫面開啟 **Settings**（佢有自己嘅頁面）：

- 如果你想撳終端機時彈出鍵盤，請啟用撳一下顯示鍵盤。
- 如果鍵盤建議干擾到 Vim、less、htop 或全螢幕 tmux 等終端機程式，請關閉輸入法建議。
- 如果你會跑長時間嘅背景任務（例如 Claude Code、Codex、shell 腳本），想喺代理需要你輸入時收到聲音或震動通知，請啟用 **Agent alerts**。
- 如果你唔想傳送任何數據，可以關閉匿名使用分析。

## 語言

Mobile SSH 跟隨系統語言。應用程式附帶阿拉伯文、孟加拉文、中文（簡體同繁體）、英文、法文、德文、印地文、印尼文、日文、馬拉地文、尼日利亞皮欽語、葡萄牙文、俄文、西班牙文、坦米爾文、泰盧固文、土耳其文同烏爾都文嘅翻譯。請喺 Android 嘅 **Settings → System → Languages**，或者喺 iOS 嘅 **Settings → General → Language & Region** 更改語言，而唔係喺應用程式入面改。

## 安全提示

只連線你信任嘅伺服器。目前嘅應用程式將已儲存嘅連線資料存喺本機，唔提供雲端保險庫或跨裝置同步。目前嘅實作亦唔會顯示已知主機確認提示，所以當主機身分重要嗰陣，請避免透過唔可信嘅網絡連線。
