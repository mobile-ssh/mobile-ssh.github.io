# கோப்பு பரிமாற்றம்

Mobile SSH இல் செயலில் உள்ள SSH இணைப்புடன் இணைக்கப்பட்ட ஒரு SFTP கோப்பு பரிமாற்றத் திரை உள்ளது. இது உங்கள் தொலைபேசி அல்லது டேப்லெட்டிலிருந்து விரைவான சேவையக பராமரிப்புக்கானது: ஒரு கட்டமைப்பைப் பதிவேற்றவும், பதிவை பதிவிறக்கவும், தொலை கோப்பை மறுபெயரிடவும், அல்லது செயலியை விட்டு வெளியேறாமல் அனுமதிகளைப் பரிசோதிக்கவும்.

## கோப்பு பரிமாற்றத்தைத் திறத்தல்

1. ஒரு SSH சேவையகத்துடன் இணைக்கவும்.
2. இணைக்கப்பட்ட டெர்மினல் பலகத்தைத் தேர்ந்தெடுக்கவும்.
3. டெர்மினல் கருவிப்பட்டியிலிருந்து **Transfer** ஐத் திறக்கவும், அல்லது தற்போதைய திரை ஆதரித்தால் பலக தலைப்பில் நீண்ட நேரம் அழுத்தவும்.
4. கோப்பு பரிமாற்றத் திரை ஒரு உள்ளக பலகம் மற்றும் ஒரு தொலை பலகத்துடன் திறக்கிறது.

செயலில் உள்ள SSH அமர்வு இல்லையென்றால், கோப்பு பரிமாற்றத்தைத் திறக்க முடியாது.

## உள்ளக மற்றும் தொலை பலகங்கள்

கோப்பு பரிமாற்றத் திரையில் இரண்டு உலாவி பலகங்கள் உள்ளன:

- **உள்ளக பலகம்:** தொலைபேசி சேமிப்பகம்.
- **தொலை பலகம்:** SFTP வழியாக சேவையக கோப்புகள்.

செயலி ஒவ்வொரு ஹோஸ்ட்டிற்கும் கடைசி பத்து தொலை பாதைகளை நினைவில் வைக்கிறது — Android இல் தொலை பலகத்தின் தலைப்பிலிருந்தும், iOS இல் கடிகார ஐகானிலிருந்தும் அவற்றைத் திறக்கவும். வரிசைப்படுத்தல் அமைப்புகளும் இரு பலகங்களுக்கும் ஒவ்வொரு ஹோஸ்ட்டிற்கும் நினைவில் வைக்கப்படுகின்றன. உள்ளக பாதை வரலாறு எதுவும் இல்லை: Android இல் உள்ளக பலகம் நீங்கள் வழங்கிய கோப்புறை, iOS இல் அது செயலியின் சொந்த ஆவணப் பகுதி.

கோப்பு பரிமாற்றத் திரை உங்கள் கணினியின் வெளிர் அல்லது இருண்ட தீமைப் பின்பற்றுகிறது, எனவே அது Mobile SSH இன் மற்ற பகுதிகளுடன் பொருந்துகிறது.

### ஒவ்வொரு அமர்வும் எங்கே திறக்கிறது (Android)

ஒரு tmux அமர்வுடன் attach ஆன பலகத்திலிருந்து File Transfer ஐத் திறந்தால், **அந்த அமர்வு** கடைசியாக வேலை செய்த இடத்திற்கே தொலை பலகம் திரும்பும், பலக தலைப்பில் அமர்வின் பெயருடன். இதற்கு முன் நீங்கள் அதைத் திறந்திராத ஒரு அமர்வு, அந்த ஹோஸ்டில் நீங்கள் அதிகம் பயன்படுத்தும் கோப்பகங்களில் தொடங்கும், பின்னர் ஹோஸ்டின் கடைசி கோப்பகம், பின்னர் உங்கள் இல்ல கோப்பகம்.

நினைவில் வைத்த கோப்பகம் இதற்கிடையில் நீக்கப்பட்டிருந்தால், உங்களைப் பிழையில் விட்டுவிடாமல், உண்மையில் பட்டியலிடக்கூடிய ஒன்று கிடைக்கும் வரை செயலி அந்தப் பட்டியலில் கீழிறங்குகிறது — மேலும் உடைந்த பாதையை மீண்டும் எழுதுவதில்லை. iOS இல் ஒவ்வொரு ஹோஸ்டுக்கும் ஒரு தொலை கோப்பகம் நினைவில் வைக்கப்படுகிறது.

## சேமிப்பக அணுகல்

Mobile SSH இரு தளங்களிலும் மொத்த சேமிப்பக அனுமதியைக் கோருவதில்லை.

Android இல் கணினியின் கோப்புறை தேர்வி மூலம் நீங்கள் **ஒரு கோப்புறையை** வழங்குகிறீர்கள், பதிவிறக்கங்கள் அங்கேயே எழுதப்படுகின்றன — மற்ற எல்லா செயலிகளும் ஏற்கனவே படிக்கக்கூடிய ஓரிடத்தில். அந்த அனுமதி செயலியை மீண்டும் திறந்தாலும் நிலைத்திருக்கும்.

iOS இல் உள்ளக பலகம் செயலியின் ஆவணப் பகுதி; கோப்புகள் கணினி ஆவண மற்றும் புகைப்படத் தேர்விகள் வழியாக வருகின்றன.

iOS இல், உள்ளக பலகம் செயலியின் சொந்த ஆவணப் பகுதியுடன் வேலை செய்கிறது, மேலும் கணினி ஆவண மற்றும் புகைப்படத் தேர்விகள் வழியாக நீங்கள் கோப்புகளைக் கொண்டு வருகிறீர்கள் — புகைப்படங்கள் மற்றும் ஆவணங்களின் பல-தேர்வு இறக்குமதி உட்பட. தனியான சேமிப்பக அனுமதி எதுவும் தேவையில்லை.

தனிப்பட்ட விசை இறக்குமதி கோப்பு பரிமாற்றத்திலிருந்து தனியானது மற்றும் கணினி கோப்பு தேர்வியைப் பயன்படுத்துகிறது.

## கோப்புகளைப் பதிவேற்றுதல்

1. உள்ளக பலகத்தைத் திறக்கவும்.
2. நீங்கள் பதிவேற்ற விரும்பும் கோப்புக்குச் செல்லவும்.
3. பதிவேற்றத்தைத் தேர்ந்தெடுக்கவும்.
4. தொலை இலக்கை உறுதிப்படுத்தவும்.
5. முன்னேற்றம் மற்றும் முடிவுக்கு பரிமாற்ற வரிசையைப் பார்க்கவும்.

பதிவேற்றங்கள் ஏற்கனவே உள்ள SSH/SFTP இணைப்பைப் பயன்படுத்துகின்றன. இணைப்பு துண்டிக்கப்பட்டால், மீண்டும் இணைத்த பிறகு மீண்டும் முயற்சிக்கவும்.

## கோப்புகளைப் பதிவிறக்குதல்

1. தொலை பலகத்தைத் திறக்கவும்.
2. நீங்கள் பதிவிறக்க விரும்பும் கோப்புக்குச் செல்லவும்.
3. பதிவிறக்கத்தைத் தேர்ந்தெடுக்கவும்.
4. உள்ளக இலக்கை உறுதிப்படுத்தவும்.
5. முன்னேற்றம் மற்றும் முடிவுக்கு பரிமாற்ற வரிசையைப் பார்க்கவும்.

பெரிய பதிவிறக்கங்களை முடிந்தவரை நிலையான நெட்வொர்க்கில் செய்யவும்.

## முழு கோப்புறைகளையும் நகலெடுத்தல்

பதிவேற்றங்கள் மற்றும் பதிவிறக்கங்கள் தனிக் கோப்புகளுக்கு மட்டும் வரம்பிடப்படவில்லை. ஒரு கோப்புறையைத் தேர்ந்தெடுத்தால், Mobile SSH முழு துணைமரத்தையும் இரு திசைகளிலும் — தொலைபேசியிலிருந்து தொலைக்கும், தொலையிலிருந்து தொலைபேசிக்கும் — நகலெடுக்கிறது; முதலில் இலக்கு அடைவுகளை உருவாக்கி, பின்னர் ஒவ்வொரு கோப்பையும் வரிசையில் வைக்கிறது. படிக்க முடியாத ஒரு துணை அடைவு மீதமுள்ள நகலெடுப்பை நிறுத்துவதில்லை; Android இல் அது "Can't list directory" எனும் தோல்வி வரிசையாக அறிக்கையிடப்படுகிறது, iOS தான் தவிர்த்ததைப் பட்டியலிடாமல் தொடர்கிறது.

## தொலை கோப்பு செயல்கள்

தேர்ந்தெடுத்த தொலை உருப்படியைப் பொறுத்து, Mobile SSH இது போன்ற செயல்களைக் காட்டலாம்:

- பதிவிறக்கு, அல்லது Android இல் **Copy to phone**.
- **சேவையகத்திலேயே** நகலெடு அல்லது நகர்த்து — `cp -r` / `mv` ஹோஸ்டிலேயே இயங்குகின்றன, பைட்டுகள் உங்கள் தொலைபேசியைத் தொடுவதே இல்லை.
- மறுபெயரிடு.
- நீக்கு.
- கோப்பு அல்லது அடைவை உருவாக்கு.
- உரை கோப்பைத் திருத்து.
- `.tar.gz` ஆக சுருக்கு.
- அனுமதிகள் — முறை (mode) மற்றும் உரிமையாளரை மாற்று, ஒரு முழு கோப்புறைக்கும் பொருத்தும் விருப்பத்துடன்.
- மற்றொரு செயலியில் திற.
- கோப்பு விவரங்களைக் காண்.

தொலை கோப்பு விவரங்களில் அனுமதி பிட்கள், உரிமையாளர், குழு மற்றும் எண்ம அனுமதி மதிப்புகள் இருக்கலாம். மற்றொரு செயல்முறை அல்லது வரிசைப்படுத்தல் கருவியால் நிர்வகிக்கப்படும் சேவையக கோப்புகளை மாற்றுவதற்கு முன் இந்த விவரங்களைப் பயன்படுத்தவும்.

கோப்பு அளவுகள் இருமை (binary) அலகுகளில் காட்டப்படுகின்றன, எனவே ஒரு தாவல் தள்ளி டெர்மினலில் `ls -h` அச்சிடுவதோடு அவை பொருந்துகின்றன.

## வரிசைப்படுத்தல் மற்றும் சமீபத்திய பாதைகள்

ஒவ்வொரு பலகமும் பெயர் அல்லது தேதியின்படி ஏறு அல்லது இறங்கு வரிசையில் வரிசைப்படுத்தலாம். Mobile SSH தேர்ந்தெடுத்த உள்ளக மற்றும் தொலை வரிசை முறைகளை சமீபத்திய பாதைகளுடன் ஒவ்வொரு ஹோஸ்ட்டிற்கும் சேமிக்கிறது, எனவே அதே சேவையகத்திற்கான மீண்டும் மீண்டும் பரிமாற்றங்கள் பழக்கமான இடங்களில் இருந்து தொடங்குகின்றன.

## பரிமாற்ற வரிசை

பரிமாற்றங்கள் வரிசையில் வைக்கப்பட்டு நிலையின்படி காட்டப்படுகின்றன, மேலும் பதிவு ஒவ்வொரு பரிமாற்றத்தையும் காட்டி உருள்கிறது — Android அவற்றை Queued / Failed / Successful எனத் தாவல்களாகவும், iOS Active / Failed / Done எனவும் பிரிக்கிறது. அடிப்படை SFTP செயல்பாடு காரணம் வழங்கும்போது தோல்வியடைந்த பரிமாற்றங்களில் காரணம் இருக்கும். iOS இல் தற்போது பரிமாற்றத்தில் உள்ள கோப்பு Active தாவலின் மேலேயே இருக்கும், மேலும் ஒரு வரிசையை இடையிலேயே ரத்து செய்யலாம்.

## கோப்புகளை செயலியிலிருந்து வெளியே எடுத்தல்

- **Android:** பதிவிறக்கங்கள் நீங்கள் வழங்கிய கோப்புறையில் வந்து சேர்கின்றன, எனவே அவை ஏற்கனவே மற்ற எல்லா செயலிகளுக்கும் தெரியும். **Open in another app** இரு பலகங்களிலும் உள்ளது; ஒரு தொலை கோப்பு முதலில் பதிவிறக்கப்பட்டு, பின்னர் ஒப்படைக்கப்படுகிறது.
- **iOS:** Mobile SSH, Files செயலியில் **On My iPhone** இன் கீழ் தோன்றுகிறது, எனவே My Phone பலகத்தில் உள்ள எதுவும் Mail, தேர்விகள் மற்றும் பிற செயலிகளிலிருந்து அணுகக்கூடியது. பதிவிறக்கிய கோப்பை நீண்ட நேரம் அழுத்தி **Open in another app** ஐத் தேர்ந்தெடுத்து அதை ஒப்படைக்கவும், AirDrop செய்யவும், அல்லது வேறு இடத்தில் சேமிக்கவும்.

## ஒரு கோப்பை அமர்வுக்குள் அனுப்புதல் (Android)

வேறு எந்த செயலியிலிருந்தும் தனக்குப் பகிரப்படும் கோப்புகளை Android ஏற்கிறது: Mobile SSH க்குப் பகிர்ந்தால், கோப்பு அந்த பலகத்தின் ஹோஸ்டில் `~/.cache/mobile-ssh` க்குப் பதிவேற்றப்பட்டு, அதன் தொலை பாதை ப்ராம்ப்ட்டில் தட்டச்சு செய்யப்படும், இதனால் உடனே அதைப் பயன்படுத்தலாம். டெர்மினல் கருவிப்பட்டியில் உள்ள 📎 பொத்தான் கணினி கோப்பு தேர்வியிலிருந்து இதையே செய்கிறது, மேலும் இரண்டுமே ஒரே நேரத்தில் பல கோப்புகளை ஏற்கின்றன.

iOS இல், ＋ பொத்தானால் கோப்புகளை உள்ளக பலகத்திற்குக் கொண்டு வந்து, அங்கிருந்து பதிவேற்றவும்.

## நடைமுறை குறிப்புகள்

- குறிப்பிட்ட கோப்பு நகர்வுகளுக்கு SFTP ஐப் பயன்படுத்தவும்; பெரிய அடைவு ஒத்திசைவுக்கு சேவையகத்தில் `rsync` போன்ற கட்டளை வரி கருவிகளைப் பயன்படுத்தவும்.
- காப்புப்பிரதி அல்லது வரிசைப்படுத்தல் மீட்பு பாதை இல்லாவிட்டால் நேரடி உற்பத்தி கோப்புகளைத் திருத்துவதைத் தவிர்க்கவும்.
- பதிவேற்றத்திற்குப் பிறகு கோப்பு தோன்றாவிட்டால், தொலை பலகத்தைப் புதுப்பிக்கவும் அல்லது இலக்குப் பாதையைச் சரிபார்க்கவும்.
- Android உள்ளக பலகம் காலியாக இருந்தால், **Pick folder** மூலம் ஒரு கோப்புறையைத் தேர்ந்தெடுக்கவும் — நீங்கள் வழங்கும் கோப்புறைக்கு மட்டுமே செயலிக்கு அணுகல் உண்டு. iOS இல், அதற்குப் பதிலாக உள்ளக பலகத்தில் கோப்புகளைச் சேர்க்க தேர்விகளைப் பயன்படுத்தவும்.
