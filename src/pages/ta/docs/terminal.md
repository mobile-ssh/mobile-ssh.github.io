# டெர்மினல்

Mobile SSH டெர்மினல் தொலைபேசி மற்றும் டேப்லெட் இயக்கத்திற்காக உருவாக்கப்பட்டது. இது ஒரு டெர்மினல் கேன்வாஸ், கூடுதல் விசை வரிசை, பல-அமர்வு பலகங்கள், உருளல் கையாளுதல் மற்றும் மீள்-இணைப்பு நடத்தையை இணைக்கிறது.

## டெர்மினல் அடிப்படைகள்

- டெர்மினல் வண்ண ஆதரவு மற்றும் கர்சர்-விசை கையாளுதலுடன் xterm-பாணி நடத்தையைப் பயன்படுத்துகிறது.
- ஸ்க்ரோல்பேக் இடையகம் அதிகபட்சம் 5000 வரிகளை வைத்திருக்கிறது.
- தட்டச்சு செய்வதற்கு முன் பலகத்தைத் தேர்ந்தெடுக்க அதைத் தட்டவும்.
- உரை அளவை மாற்ற டெர்மினல் பலகத்தில் கிள்ளவும். சைகை நிலைத்த பிறகு Mobile SSH தொலை PTY இன் அளவை மாற்றுகிறது.
- முழுத்திரை பயன்முறையில் நுழைய பலகத்தில் இருமுறை தட்டவும் (அல்லது அதன் விரிவாக்கப் பொத்தானைப் பயன்படுத்தவும்). கட்டத்திற்குத் திரும்ப Android இல் Back ஐ அல்லது iOS இல் சுருக்கப் பொத்தானைப் பயன்படுத்தவும்.

## பல-அமர்வு கட்டம்

Mobile SSH ஒரே நேரத்தில் எட்டு SSH அமர்வுகள் வரை இயக்க முடியும். ஒவ்வொரு அமர்வும் டெர்மினல் கட்டத்தில் ஒரு பலகமாகத் தோன்றும். பலக தலைப்பு தற்போதைய இலக்கை அல்லது தலைப்பைக் காட்டுகிறது. தேர்ந்தெடுக்க பலகத்தைத் தட்டவும், அல்லது மற்றொரு இணைப்பைத் தொடங்க **+ Add Session** ஐப் பயன்படுத்தவும்.

பலகத்தை மூடுவது அந்த SSH அமர்வைத் துண்டிக்கிறது. தொடக்கத் திரைக்குத் திரும்புவது செயலில் உள்ள அமர்வுகளை **Active Sessions** வழியாகக் கிடைக்கச் செய்கிறது.

## கூடுதல் விசை வரிசை

Android மற்றும் iOS இரண்டிலும், கூடுதல் விசை வரிசை திரை விசைப்பலகைக்கு மேலே தோன்றும் மற்றும் தொடு விசைப்பலகைகளில் சிரமமான டெர்மினல் விசைகளை வழங்குகிறது:

- `ESC`
- `TAB`
- `CTRL`
- `Shift`
- அம்பு விசைகள்
- `HOME`
- `END`
- `PGUP`
- `PGDN`
- விசைப்பலகை மாற்றி

`CTRL` மற்றும் `Shift` அடுத்த இணக்கமான உள்ளீட்டிற்கான ஒட்டும் மாற்றிகளாகச் செயல்படுகின்றன. எடுத்துக்காட்டாக, `CTRL` ஐத் தட்டி, பின்னர் Ctrl-C அனுப்ப `C` ஐத் தட்டச்சு செய்யவும்.

## விசைப்பலகை நடத்தை

டெர்மினல் திரை விசைப்பலகைக்கு ஒரு உள்ளமை நேரடி-கடத்தல் இணைப்பைப் பயன்படுத்துகிறது: நீங்கள் தட்டச்சு செய்யும்போது ஒவ்வொரு எழுத்தும் தொலை ஷெல்லுக்கு அனுப்பப்படுகிறது, தானியங்கு திருத்தம் மற்றும் முன்கணிப்பு பரிந்துரைகள் அணைக்கப்பட்டிருப்பதால் விசைப்பலகை உள்ளீட்டை ஷெல்லை அடையும் முன் மீண்டும் எழுதுவதே இல்லை. இது Vim, tmux, htop, less, அசாதாரண விசை-கார்டுகளைப் பயன்படுத்தும் ஷெல்கள் மற்றும் தொலை கடவுச்சொல் ப்ராம்ப்ட்களை கணிக்கக்கூடியதாக வைக்கிறது — முடக்குவதற்கு எந்த பரிந்துரை இடையகமும் இல்லை.

- **விசைப்பலகையைக் காட்ட டெர்மினலைத் தட்டவும்:** இயக்கப்பட்டால், டெர்மினலைத் தட்டுவது முறைமையை திரை விசைப்பலகையைக் காட்டச் சொல்கிறது.

மென்-விசைப்பலகை குரல் கட்டளையிடல் தொடர்ந்து செயல்படும்: சொல்லப்பட்ட உரை வேறு எந்த தட்டச்சு உள்ளீட்டையும் போலவே நேரடியாக ஷெல்லுக்கு அளிக்கப்படுகிறது.

## வன்பொருள் விசைப்பலகைகள்

வெளிப்புற மற்றும் Bluetooth விசைப்பலகைகள் Android மற்றும் iOS இரண்டிலும் டெர்மினலை நேரடியாக இயக்குகின்றன. சாதாரண எழுத்துகளுக்கு அப்பால், Mobile SSH அம்பு விசைகள், `Home`/`End`, `PgUp`/`PgDn`, `Insert`, `Delete`, `Esc`, செயல்பாட்டு விசைகள் `F1`–`F12`, `Ctrl`+விசை மற்றும் `Alt`/`Option`-ஐ-Meta ஆக்கும் கார்டுகள், மற்றும் `Shift`+`Tab` ஆகியவற்றை வரைபடமாக்குகிறது. மாற்றி விசைகள் கூடுதல் விசை வரிசையின் ஒட்டும் மாற்றிகளுடன் இணைந்து செயல்படுகின்றன.

## ஒட்டுதல்

அதைக் கோரும் ஒரு நிரலில் (bash, Vim மற்றும் பிற bracketed-paste செயலிகள்) ஒட்டுவது bracketed-paste குறிப்பான்களில் மடிக்கப்படுகிறது, இதனால் பல-வரி கிளிப்போர்டு உள்ளடக்கம் வரிக்கு வரி தானாக இயக்கப்படுவதற்குப் பதிலாக உரையாகச் செருகப்படுகிறது. உண்மையான ஒட்டுதல்கள் மட்டுமே மடிக்கப்படுகின்றன; தட்டச்சு செய்யப்பட்ட மற்றும் சொல்லப்பட்ட உரை தீண்டப்படாது.

## தேர்ந்தெடு, நகலெடு, பகிர்

உங்கள் விரலின் கீழுள்ள சொல்லைத் தேர்ந்தெடுக்க டெர்மினலுக்குள் நீண்ட நேரம் அழுத்தவும், பின்னர் கைப்பிடிகளை இழுத்துச் சரிசெய்யவும். தேர்வு கருவிப்பட்டி மூன்று செயல்களை வழங்குகிறது:

- **Copy** — தேர்ந்தெடுத்த உரையை முறைமைக் கிளிப்போர்டில் வைக்கும். அதன் பிறகு தேர்வு தனிப்படுத்தப்பட்டே இருக்கும், எனவே அதை பகிரலாம், மீண்டும் நகலெடுக்கலாம் அல்லது நீட்டிக்கலாம்.
- **Share** — தேர்ந்தெடுத்த உரையை முறைமைப் பகிர்வுத் தாளுக்கு (மின்னஞ்சல், குறிப்புகள், செய்தி அனுப்புதல் போன்றவை) அனுப்பும்.
- **Select all** — தேர்வை முழு புலப்படும் டெர்மினல் இடையகம் வரை விரிவாக்கி, பின்னர் Copy அல்லது Share செய்யும்.

## டெர்மினலில் தேடு

முழு டெர்மினல் இடையகத்தையும் — ஸ்க்ரோல்பேக் மற்றும் புலப்படும் திரையையும் — தேடி, பொருத்தங்களுக்கு இடையே தாவுங்கள். டெர்மினல் கட்டுப்பாடுகளிலிருந்து தேடலைத் திறந்து, ஒரு வினவலைத் தட்டச்சு செய்து, கண்டெடுப்புகள் வழியே செல்லுங்கள். இது Android மற்றும் iOS இரண்டிலும் செயல்படுகிறது.

## வண்ணம், சாய்வெழுத்துகள் மற்றும் தொலைதூர கிளிப்போர்டு

- டெர்மினல் **24-bit true color** மற்றும் **சாய்வெழுத்துகளை** (italics) வழங்குகிறது, எனவே தீம் செய்யப்பட்ட ப்ராம்ப்ட்கள், தொடரியல் தனிப்படுத்தல் மற்றும் TUI-கள் டெஸ்க்டாப்பில் இருப்பது போலவே தோற்றமளிக்கும்.
- **OSC 52 கிளிப்போர்டு:** ஒரு தொலைதூர நிரல் உரையை நகலெடுக்கும்போது (tmux `set-clipboard`, ஒரு Vim/Neovim OSC 52 yank), அது உங்கள் தொலைபேசியின் கிளிப்போர்டுக்கு வந்து சேரும் — எனவே சர்வரிலிருந்து நகலெடுத்து உள்ளக செயலியில் ஒட்டலாம்.
- Android-இல், வழங்கப்பட்ட **Nerd Font**, கணினி எழுத்துரு காலி பெட்டிகளாகக் காட்டும் powerline, starship, devicon மற்றும் Material Design ஐகான் க்ளிஃப்களை வரைகிறது, மேலும் அகன்ற CJK, emoji மற்றும் இணை எழுத்துகள் சரியாக அளக்கப்படுகின்றன.

## உருளல்

Mobile SSH டெர்மினல் நிலையின் அடிப்படையில் உருளல் சைகைகளை வழிநடத்துகிறது:

- சாதாரண ஷெல் வெளியீட்டில், ஸ்வைப் செய்வது உள்ளக ஸ்க்ரோல்பேக் இடையகத்தை உருட்டுகிறது.
- மவுஸ்-பயன்முறை டெர்மினல் செயலிகளில், உருளல் மவுஸ்-வீல் எஸ்கேப் வரிசைகளை அனுப்புகிறது.
- மவுஸ் பயன்முறை இல்லாத மாற்று-திரை செயலிகளில், பல tmux அமர்வுகள் போல, உருளல் tmux நகல் பயன்முறையில் நுழைந்து வரி உருளல் கட்டளைகளை அனுப்புகிறது.

பின்னோக்கி உருட்டிய நிலையில் தட்டச்சு செய்தால், Mobile SSH நேரடி டெர்மினல் காட்சிக்குத் திரும்புகிறது.

## tmux நடத்தை

Mobile SSH வெளிச்செல்லும் tmux attach மற்றும் new-session கட்டளைகளைக் கவனிக்கிறது, எடுத்துக்காட்டாக:

```bash
tmux attach -t work
tmux a -t work
tmux new -A -s work
```

நீங்கள் tmux இல் இருக்கும்போது இணைப்பு துண்டிக்கப்பட்டால், செயலி அந்த சேவையகத்தின் கடைசி tmux அமர்வுப் பெயரை நினைவில் வைத்து, மீள்-இணைப்புக்குப் பிறகு மீண்டும் இணைக்க முயற்சிக்கலாம். வெளிப்படையான அமர்வுப் பெயர் கவனிக்கப்படாவிட்டாலும், நீங்கள் மாற்று-திரை tmux போன்ற அமர்வில் இருந்தீர்கள் என்று செயலிக்குத் தெரிந்தால், அது பொதுவான `tmux attach` ஐ முயற்சிக்கலாம்.

இந்த நடத்தை சிறந்த-முயற்சி. தொலை tmux அமர்வு இனி இல்லையென்றால், தொலை ஷெல் கிடைக்கும்.

## Agent alerts

Mobile SSH செயலில் உள்ள அமர்வின் டெர்மினல் வெளியீட்டை கவனித்து, தொலை முகவர் உள்ளீட்டிற்காக காத்திருக்கிறது என்பதை சுட்டும் முறைகளை இனங்காண முடியும். ஒரு பொருத்தம் கண்டறியப்பட்டால் — எடுத்துக்காட்டாக, Claude Code அல்லது Codex ஒரு ப்ராம்ப்டிற்காக இடைநிறுத்தினால் — செயலி விருப்பமான ஒலி மற்றும் அதிர்வுடன் ஒரு அறிவிப்பை அனுப்புகிறது.

அமைக்க:

1. தொடக்கத் திரையிலிருந்து **Settings** ஐ திறக்கவும்.
2. **Agent alerts** ஐ இயக்கவும்.
3. ஒரு அறிவிப்பு ஒலி மற்றும் அதிர்வு முறையைத் தேர்ந்தெடுக்கவும்.

தலைப்பணிகள், குறிப்புகள், செய்திப்பதிவு உட்பட தற்போது செயலில் உள்ள எந்த ஆடியோ வெளியீட்டு வழியிலும் எச்சரிக்கை ஒலிக்கும், எனவே வீடியோ பார்க்கும்போது அல்லது தொலைபேசி பூட்டப்பட்டிருக்கும்போதும் அதை கேட்கலாம். Mobile SSH பின்னணியில் இருக்கும்போதும் அறிவிப்பு தோன்றும்.

Agent alert முறைகள் புலப்படும் டெர்மினல் வெளியீட்டுடன் பொருத்தப்படுகின்றன. உங்கள் தொலை கருவி அடையாளம் காணக்கூடிய ப்ராம்ப்ட் வரியை (பயனர்பெயர், `?`, அடைப்புக்குறி கொண்ட கேள்வி) வெளியிட்டால், செயலி அதை தானாகவே எடுத்துக்கொள்ளலாம். எச்சரிக்கைகள் மிகவும் அடிக்கடி அல்லது அறவே வராவிட்டால், Settings இல் உணர்திறனை சரிசெய்யவும்.

## முழுத்திரை டெர்மினல் நிரல்கள்

Vim, less, htop, ncurses கருவிகள் மற்றும் tmux பலகங்கள் போன்ற நிரல்களுக்கு:

- உள்ளீடு நேரடியாக நிரலுக்குக் கடத்தப்படுகிறது — இடையூறு செய்வதற்கு எந்த தானியங்கு திருத்தமோ பரிந்துரை இடையகமோ இல்லை.
- `ESC`, அம்புகள், `PGUP` மற்றும் `PGDN` க்கு கூடுதல் விசை வரிசையைப் பயன்படுத்தவும்.
- உரை மிகச் சிறியதாக இருந்தால் கிள்ளு பெரிதாக்கலைப் பயன்படுத்தி, பின்னர் தொலை டெர்மினல் அளவு நிலைபெறும் வரை சிறிது காத்திருக்கவும்.
