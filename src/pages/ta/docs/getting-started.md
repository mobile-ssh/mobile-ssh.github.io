# தொடங்குதல்

Mobile SSH என்பது உங்கள் சொந்த Linux, Unix, நெட்வொர்க், IoT அல்லது டெவலப்மென்ட் சேவையகங்களுடன் இணைக்க உதவும் Android மற்றும் iOS க்கான ஒரு SSH கிளையன்ட். நீங்கள் சேவையக முகவரியையும் சான்றுகளையும் வழங்குகிறீர்கள்; செயலி ஒரு ஊடாடும் SSH டெர்மினலைத் திறக்கிறது.

## தேவைகள்

- Android 8.0 அல்லது புதியது, அல்லது iOS 16 அல்லது புதியது (iPhone அல்லது iPad).
- சாதனத்திலிருந்து உங்கள் SSH சேவையகத்திற்கு நெட்வொர்க் அணுகல்.
- SSH சேவையகத்தின் ஹோஸ்ட்பெயர் அல்லது IP முகவரி, போர்ட், பயனர்பெயர், மற்றும் கடவுச்சொல் அல்லது தனிப்பட்ட விசை.
- உள்ளூர்ப் பரிமாற்றத்திற்கு முறைமைத் தேர்வில் கோப்புறை/கோப்பு தேரவும். முழுச் சேமிப்பு அணுகல் இரு தளங்களுக்கும் தேவையில்லை.

## செயலியை நிறுவுதல்

- **Android:** Mobile SSH தற்போது Google Play இல் ஒரு மூடிய சோதனையாக (closed test) உள்ளது. சாதனத்தில் ஒரு மொபைல் உலாவியில் ஒப்புதல் இணைப்பைத் திறந்து — Google Play செயலிக்குள் அல்ல, ஏனெனில் அங்கே சோதனை தெரியாமல் போகலாம் — நீங்கள் பயன்படுத்தப்போகும் Google கணக்குடன் சேரவும். அதன் பிறகு மற்ற எந்த செயலியையும் போலவே Play இலிருந்து நிறுவப்பட்டு புதுப்பிக்கப்படும்.
- **iOS:** iOS செயலி TestFlight இல் பொது பீட்டாவாக வழங்கப்படுகிறது. Apple இன் TestFlight செயலியை நிறுவி, பின்னர் நிறுவவும் புதுப்பிப்புகளைப் பெறவும் தளத்தின் முகப்புப் பக்கத்திலிருந்து Mobile SSH அழைப்பு இணைப்பைத் திறக்கவும்.

## சேவையகத்துடன் இணைத்தல்

1. Mobile SSH ஐத் திறக்கவும்.
2. **+ Add Session** ஐத் தட்டி சேமித்த சேவையகத்தை தேடவும், அல்லது அந்தத் திரையிலிருந்தே புதிய சேவையகத்தைச் சேர்க்கவும்.
3. புதிய சேவையகம் சேர்க்கும்போது ஹோஸ்ட், போர்ட், பயனர்பெயர் மற்றும் அங்கீகார விவரங்களை உள்ளிடவும்.
4. டெர்மினல் அமர்வைத் திறக்க சேவையகத்தைத் தட்டவும்.
5. இன்னும் இயங்கும் அமர்வுகளுக்குத் திரும்ப முகப்புத் திரையில் **Active Sessions** ஐப் பயன்படுத்தவும்.

இயல்புநிலை SSH போர்ட் `22`. உங்கள் சேவையகம் வேறு போர்ட்டைப் பயன்படுத்தினால், அந்த போர்ட்டை சேவையக சுயவிவரத்தில் உள்ளிடவும்.

## சேவையக அடையாளச் சரிபார்ப்பு

இரு செயலிகளும் சான்று அனுப்புமுன் SSH அடையாளம் சோதிக்கும். மாற்று முகவரிகள், இடைநிலை ஹோஸ்ட்களிலும் மாறிய விசை இணைப்பைத் தடுக்கும்.

- **Android:** **புதிய SSH அடையாளங்களைத் தானாக ஏற்று** இயல்பாக இயக்கம். முதல் சாதாரண விசை சேமிக்கும்; அடுத்தவை பொருந்த வேண்டும். **அமைப்புகள் → பொதுவானவை → பாதுகாப்பு**-ல் அணைத்து, ஏற்று மீண்டும் இணையுமுன் SHA-256 கைரேகையை நிர்வாகியுடன் ஒப்பிடவும்.
- **iOS:** அறியாத விசைக்கு உறுதி வேண்டும். நம்பக வழியில் கைரேகை பார்த்து **நம்பி மீண்டும் இணை** தேரவும்.

சேமித்த அடையாளங்களை அமைப்பில் பார்க்கவும். இரு தளங்களும் நிர்வாகி வழங்கிய ஹோஸ்ட் விசை ரத்துசெய்தலை ஏற்கும்; Android ஹோஸ்ட் சான்று அதிகாரிகளையும் ஆதரிக்கும். iOS-ல் வரம்பிட்ட OpenSSH `@revoked` Ed25519/ECDSA பதிவுகளுக்கு **அமைப்புகள் → சேவையக அடையாளங்கள் → ரத்தான விசைகளை இறக்குமதி செய்** பயன்படுத்தவும். புதிய இணைப்பு, மீளிணைப்பில் முன்பு நம்பியவை உட்பட ரத்தான விசைகள் தடுக்கப்படும்; இறக்குமதி தற்போதைய இணைப்புகளை மூடாது. iOS ஹோஸ்ட் சான்று/CA இறக்குமதி தராது. நம்பிக்கை சாதனத்திலேயே, காப்பிலிருந்து வராது. மாறிய அல்லது ரத்தான விசையை நீக்குமுன் தடைக்கான காரணம் சோதிக்கவும்.

## ஒரு போக்குவரத்தைத் தேர்ந்தெடுத்தல்

ஒரு சேவையகத்தைச் சேர்க்கும்போது அல்லது திருத்தும்போது, Mobile SSH எப்படி இணைக்கிறது என்பதை **Transport** தேர்வி தீர்மானிக்கிறது:

- **SSH** -- ஒரு நிலையான SSH இணைப்பு (இயல்புநிலை).
- **Eternal Terminal** -- நெட்வொர்க் துண்டிப்புகள், உறக்கம் மற்றும் IP மாற்றங்களைத் தாங்கும் ஒரு நெகிழ்திறன் அமர்வு. ஹோஸ்டில் `etserver` இல்லையென்றால், Mobile SSH SSH வழியாக உங்களுக்காக ஒன்றை நிறுவ முடியும். விவரங்களுக்கு **டெர்மினல்** வழிகாட்டியைப் பார்க்கவும்.

Android சோதனை **Teleport** ப்ராக்ஸியும் தரும். சேமித்த இடைநிலை வழிக்கு SSH தேவை; Eternal Terminal-உடன் சேராது.

## சேவையகங்களைச் சேமித்தல்

சேமித்த சேவையகங்கள் இணைப்பு இலக்கையும் விருப்பத் தேர்வான டன்னல் கட்டமைப்பையும் வைத்திருக்கின்றன. ஒரு சேமித்த சேவையகத்தில் இவை இருக்கலாம்:

- ஹோஸ்ட்பெயர் அல்லது IP முகவரி.
- SSH போர்ட்.
- பயனர்பெயர்.
- கடவுச்சொல் அல்லது தனிப்பட்ட விசை விவரங்கள்.
- விருப்பத் தேர்வான உள்ளக போர்ட்-முன்னனுப்பல் விதிகள்.
- அதே கணினிக்கான விருப்பத் தேர்வான கூடுதல் முகவரிகள் (கீழே காண்க).
- விருப்ப இடைநிலை ஹோஸ்ட்கள், **இணையும்போது இணை**: தானாக, எதுவுமில்லை, tmux, herdr அல்லது Zellij.

நீங்கள் மீண்டும் மீண்டும் அணுகும் ஹோஸ்ட்களுக்கு சேமித்த சேவையகங்களைப் பயன்படுத்தவும். ஒரு சேமித்த சேவையகம் உங்கள் தற்போதைய செயலில் உள்ள அமர்வை விட வேறு ஹோஸ்ட்டை சுட்டிக்காட்டினால், Mobile SSH தேர்ந்தெடுத்த இலக்கிற்கு புதிய இணைப்பைத் தொடங்கும்.

### பல முகவரிகள் (LAN/VPN ரோமிங்)

நீங்கள் எங்கிருக்கிறீர்கள் என்பதைப் பொறுத்து அதே கணினியை பல்வேறு முகவரிகளில் அடிக்கடி அணுகலாம் — வீட்டு Wi-Fi IP-ஐ எதிராக VPN IP. மாற்று முகவரிகளை சேவையகத்தின் திருத்த உரையாடலில் சேர்க்கவும், தேவைப்பட்டால் ஒவ்வொன்றுக்கும் அதன் சொந்த போர்ட்டுடன். நீங்கள் இணைக்கும்போது, ஒன்று பதிலளிக்கும் வரை Mobile SSH முகவரிகளை வரிசையில் முயற்சிக்கிறது, மேலும் கடைசியாக வேலை செய்த முகவரியை நினைவில் வைத்து அடுத்த முறை அதை முதலில் அழைக்கிறது. ஒரு நெட்வொர்க் மாற்றம் (எடுத்துக்காட்டாக VPN-ஐ விட்டு வெளியேறுவது) செத்த வழி நேரம் முடிவடையும் வரை காத்திருக்காமல், தற்போது அணுகக்கூடிய முகவரிக்கு உடனடி மீள்-இணைப்பைத் தூண்டுகிறது.

### இடைநிலை ஹோஸ்ட்கள்

முதலில் வாயில் சேவையகங்களைச் சேமித்து இலக்கின் ஜம்ப் அமைப்பில் வரிசையாகத் தேரவும். இரு தளங்களில் விரித்தபின் எட்டு SSH படிகள். ஒவ்வொரு படிக்கும் சொந்தச் சான்று/சோதனை; இலக்கு முந்தைய படியிலிருந்து கிடைத்தால் போதும். காணாத சேவையகம், சுழற்சி, தோல்வியில் நேரடியாக இணையாமல் நிற்கும். முனையம், SFTP, உள்ளூர் முன்னனுப்பல், ஆதரிக்கும் SSH பணிகள் அதே வழி பயன்படுத்தும்.

## சான்றுகளைச் சேமித்தல்

**Credentials** திரை, மீண்டும் பயன்படுத்தக்கூடிய பயனர்பெயர்/கடவுச்சொல் அல்லது பயனர்பெயர்/தனிப்பட்ட-விசை பதிவுகளைச் சேமிக்கிறது. சேமித்த சான்றுகளை சேவையக அமைப்பு உரையாடலிலிருந்து தேர்ந்தெடுக்கலாம், இதனால் ஒவ்வொரு ஹோஸ்ட்டிற்கும் அதே உள்நுழைவுத் தகவலை மீண்டும் உள்ளிட வேண்டியதில்லை.

சான்று பதிவுகள் சாதனத்தில் உள்ளூரில் சேமிக்கப்படுகின்றன — iOS இல், ரகசியங்கள் கணினியின் Keychain இல் வைக்கப்படுகின்றன. கடவுச்சொற்கள், கடவுச்சொற்றொடர்கள் அல்லது தனிப்பட்ட விசைகளைச் சேமித்தால் சாதனத்தைத் திரைப் பூட்டால் பாதுகாக்கவும்.

## தனிப்பட்ட விசைகளைப் பயன்படுத்துதல்

Mobile SSH ஒட்டப்பட்ட தனிப்பட்ட விசைகளையும் கணினி கோப்பு தேர்வி மூலம் விசை இறக்குமதியையும் ஆதரிக்கிறது. Android இல் செயலி Ed25519, ECDSA (P-256/384/521) மற்றும் RSA விசைகளை ஆதரிக்கிறது; iOS இல் Ed25519 மற்றும் ECDSA (P-256/384/521) விசைகளை ஆதரிக்கிறது. DSA (`ssh-dss`) இரு தளங்களிலும் ஆதரிக்கப்படவில்லை. கடவுச்சொற்றொடரால் குறியாக்கம் செய்யப்பட்ட விசையை இரு தளங்களுமே திறக்க முடியும் — கடவுச்சொல்/கடவுச்சொற்றொடர் புலத்தில் அந்தக் கடவுச்சொற்றொடரை உள்ளிடவும்.

தனிப்பட்ட விசையைப் பயன்படுத்த:

1. **Credentials** அல்லது சேவையக திருத்த உரையாடலைத் திறக்கவும்.
2. தனிப்பட்ட விசை உரையை ஒட்டவும், அல்லது **Import from file** ஐத் தேர்ந்தெடுக்கவும்.
3. விசை குறியாக்கம் செய்யப்பட்டிருந்தால் கடவுச்சொல்/கடவுச்சொற்றொடர் புலத்தில் விசை கடவுச்சொற்றொடரை உள்ளிடவும்.
4. சான்று அல்லது சேவையகத்தைச் சேமிக்கவும்.

தனி விசை முறைமைக் கோப்புத் தேர்வில் இறங்கும்; பிற சேமிப்பு அணுகல் கிடைக்காது. கோப்புப் பரிமாற்றத்திற்கு தனிக் கோப்புறை/கோப்புத் தேர்வு.

Android USB/NFC **FIDO2 பாதுகாப்பு விசைகள்**: பதிவு அல்லது OpenSSH சான்று இறக்கி தொடுதல்/PIN பின்பற்றவும். சான்று ஏற்றுமதி/மீட்புக்குப் பிறகும் அதே விசை வேண்டும். **SSH முகவர் முன்னனுப்பல்** சேவையகத்திற்கு தனி அனுமதி; சேமித்த சான்றுகள் கையொப்ப கோரிக்கைக்குப் பதிலளிக்கும், ஒவ்வொரு முறையும் விருப்ப உறுதி. கையொப்பம் கேட்க நம்பும் சேவையகத்தில் மட்டும் இயக்கவும். iOS பாதுகாப்பு விசை அங்கீகாரம்/முகவர் முன்னனுப்பல் தராது.

## முகப்புத் திரை

முகப்புத் திரை ஒரு காலி இணைப்புப் படிவத்தைத் திறப்பதற்குப் பதிலாக, "நான் எதற்குத் திரும்பிச் செல்ல முடியும்?" என்பதற்குப் பதிலளிக்கும் வகையில் கட்டப்பட்டுள்ளது:

- **Continue** இப்போது உயிருடன் உள்ள இணைப்புகளைப் பட்டியலிடுகிறது; ஒரு இணைப்பில் ஒன்றுக்கு மேற்பட்ட பலகங்கள் இருந்தால் அவற்றின் எண்ணிக்கையையும் காட்டுகிறது. ஒரு வரிசையைத் தட்டினால் அதற்கே திரும்பிச் செல்லலாம்.
- **Tmux sessions** உங்கள் சேமித்த சேவையகங்களில் இயங்குவதைப் பட்டியலிடுகிறது. இது செயலி ஏற்கனவே சேமித்து வைத்த ஒரு ஸ்னாப்ஷாட்டிலிருந்து வரைவதால், நெட்வொர்க்கே இல்லாமலும் உடனடியாகத் தோன்றுகிறது — ஒவ்வொரு வரிசையிலும் அந்த ஸ்னாப்ஷாட்டின் வயது குறிக்கப்பட்டிருக்கும், ஒன்றைத் தட்டினால் இணைத்து அந்த அமர்வுடன் attach செய்யும். ஸ்னாப்ஷாட்கள் சில மணி நேரங்களுக்குப் பிறகு மங்கி, ஒரு வாரத்திற்குப் பிறகு நீக்கப்படுகின்றன.
- iOS **அண்மையவை** பட்டியல் **புதிய இணைப்பு** தாளில் உள்ளது; தேர்வு இணைப்புப் படிவத்தை நிரப்பும்.

Android **VPN** கட்டம் உள்ளமைந்த கிளையண்ட்களைத் திறக்கும்; **பற்றி** அமைப்புகளில். தளத்தின் VPN வழிகாட்டி **போர்ட் முன்னனுப்பல்** பகுதியில்.

எதுவும் உயிருடன் இல்லாமல், தேக்ககத்திலும் ஒன்றும் இல்லாதபோது, திரை அதைச் சொல்லி **Servers** பக்கம் உங்களை வழிநடத்தும்.

## சேமித்த சேவையகங்களுக்குப் பெயரிடுதலும் தேடுதலும்

ஒரு சேமித்த சேவையகம் ஒரு பெயரைச் சுமக்கலாம் — "Home NAS", "Prod web" — அப்போது பட்டியல் முகவரிக்குப் பதிலாக அந்தப் பெயரைக் காட்டும். பெயர் தெளிவற்றதாகும் நிலையில் — இரண்டு வரிசைகள் ஒரே பெயரைப் பகிர்ந்தால், அல்லது தேடல் நடக்கும்போது — முகவரி தானாகவே திரும்பி வரும், இதனால் வரிசைகளை எப்போதும் வேறுபடுத்தி அறியலாம்.

**Saved Servers** பக்கத்தில் உள்ள தேடல் புலத்தைத் தட்டி வடிகட்டவும். தேடல் பெயர், பயனர், ஹோஸ்ட், போர்ட், சான்று மற்றும் எந்த மாற்று முகவரிகளுடனும் பொருந்தும். **+ Add Session** திரையும் தேடலுடன் திறக்கப்படுகிறது, இதனால் ஒரே படியில் சேமித்த சேவையகத்தை கண்டுபிடித்து இணைக்கலாம்.

சேவையகங்களை கோப்புறைகளாக ஒழுங்கமைக்கலாம். ஒரு கோப்புறை சுருங்கும், சுருக்கப்பட்டிருந்ததை நினைவில் வைக்கும், மறுவரிசைப்படுத்தவோ மறுபெயரிடவோ முடியும்; ஒன்றை நீக்கினால் அதன் சேவையகங்கள் நீக்கப்படாமல் **Ungrouped** க்கு நகர்த்தப்படும்.

## உங்கள் அமைப்பின் ஒரு பகுதியை ஏற்றுமதி செய்தல்

Servers மற்றும் Credentials திரைகளில் உள்ள **Export selected…** பட்டியலை ஒரு தேர்வுப்பெட்டி பட்டியலாக மாற்றுகிறது, இதனால் எல்லாவற்றையும் ஏற்றுமதி செய்யாமல் மூன்று சேவையகங்களை மட்டும் கொடுக்க முடியும். ஒரு கோப்புறைத் தலைப்பைத் தட்டினால் அந்தக் கோப்புறை முழுவதும் சேரும். கடவுச்சொற்றொடர் கொடுத்தால் ஏற்றுமதிகள் குறியாக்கம் செய்யப்படும் — கொடுக்கவில்லை என்றால் கோப்பு கடவுச்சொற்களையும் தனிப்பட்ட விசைகளையும் சாதா உரையாக வைத்திருக்கும், அதை எழுதும் முன்பே செயலி அதைச் சொல்லும்.

முழுக் காப்பிற்கு Android **அனைத்தையும் ஏற்றுமதி (காப்பு)** அல்லது iOS **காப்பும் மீட்பும்**. தற்போதைய பதிப்புகள் சேவையகம், சான்று, மொழி, கூடுதல் விசை, multiplexer வரிசை சேர்க்கும்; Android VPN/SOCKS-உம். முழுக் கோப்பையும் கடவுத்தொடரால் பாதுகாக்கவும்.

இரு செயலிகளும் தற்போதைய வடிவம் 2, பழைய பட்டியல் காப்புகளைப் படிக்கும். **இணை** கொடுத்த பகுதிகளைச் சேர்த்து பழையவற்றை வைத்திருக்கும்; **மாற்று** கோப்பிலுள்ள பகுதிகளை மாற்றும், அமைப்புப் பகுதி இருந்தால் விடுபட்ட விருப்பங்களை இயல்பாக்கும். இல்லாத பகுதிகள் மாறாது. ஆதரிக்காத அமைப்பு குறிப்பிடப்படும்; மற்ற செயலியின் அம்சமாக மாறாது. இறக்குமதி VPN தொடங்காது.

அடையாளம், செயலில் அமர்வு, முறைமை அனுமதி, தேர்ந்த கோப்புறை அணுகல் மீளாது. புதிய சாதனத்தில் ஹோஸ்ட் சோதித்து கோப்புறை அனுமதி கொடுக்கவும். பழைய பதிப்பு புதிய முழுக் காப்பைப் படிக்காது.

## செயலில் உள்ள அமர்வுகள்

அமர்வு இயங்கினால் முகப்பில் எண்ணிக்கையுடன் **செயலில் உள்ள அமர்வுகள்**; தட்டி முனையக் கட்டத்திற்குத் திரும்பவும். Android நிரந்தர அறிவிப்பு செயலில் ஹோஸ்ட்களைக் காட்டி இணைப்புக் கட்டுப்பாடு திறக்கும்.

முகப்புத் திரைக்குத் திரும்புவது செயலில் உள்ள SSH அமர்வுகளைத் துண்டிப்பதில்லை; பலகங்களை மூடுவது அல்லது டெர்மினல் செயல்பாட்டை முடிப்பது அவற்றைத் துண்டிக்கிறது.

## முதல் பயனுள்ள அமைப்புகள்

முகப்புத் திரையிலிருந்து **Settings** ஐத் திறக்கவும் (அதற்கென்று தனிப்பக்கம் உண்டு):

- டெர்மினலைத் தட்டும்போது விசைப்பலகை மேலெழ வேண்டுமா என்பதை முடிவு செய்யவும். இரு தளங்களும் எதிரெதிரான இயல்புநிலைகளுடன் வருகின்றன: Android இல் ⌨ பொத்தானிலிருந்து மட்டுமே விசைப்பலகை தோன்றும், iOS இல் ஒரு தட்டல் அதை மேலெழச் செய்யும்.
- டெர்மினலின் **உரை அளவு**, **எழுத்துரு**, **நிறத் திட்டம்** மற்றும் **ஸ்க்ரோல்பேக்** அளவை அமைக்கவும், மேலும் ஒரு செயலி **தீம்** (System, Light அல்லது Dark) ஐத் தேர்ந்தெடுக்கவும்.
- நீண்ட பின்னணி பணிகள் (Claude Code, Codex, ஷெல் ஸ்கிரிப்ட்கள்) இயக்கும்போது முகவருக்கு உங்கள் உள்ளீடு தேவைப்படும்போது அறிவிப்பு வேண்டுமெனில் **Agent alerts** ஐ இயக்கவும். முகவர்கள் எப்படித் தங்களைப் பற்றி அறிவிக்கின்றன என்பதற்கு **டெர்மினல்** வழிகாட்டியைப் பார்க்கவும்.
- Android இல், **Keep sessions running in background** இயல்பாகவே இயக்கத்தில் இருக்கிறது, எனவே செயலியை விலக்கிவிட்ட பிறகும் ஷெல்களும் முகவர்களும் உயிர் வாழ்கின்றன.
- இரு தள அமைப்புகளிலும் பெயரற்ற பயன்பாட்டுப் பகுப்பாய்வு சுவிட்ச்; அணைத்தால் புதிய நிகழ்வுச் சேகரிப்பு நிற்கும்.
- iOS **குரல் உள்ளீடும் பரிந்துரைகளும்** இயல்பாக இயக்கம். குரல்/தான்திருத்தமின்றி நேரடி உள்ளீட்டிற்கு அணைத்துப் புதிய பலகை திறக்கவும்.
- தொலை அறிவிப்பு, கட்டளை முடிவு, தொலை கிளிபோர்டு வாசிப்பு தனி விருப்ப அனுமதிகள்; வேண்டியவற்றை மட்டும் இயக்கவும்.

## சொருகிகள்

சொருகிகள் Mobile SSH ஐ கூடுதல் பணிப்பாய்வுகளால் விரிவாக்குகின்றன. முகப்புத் திரையிலிருந்து **Plugins** ஐத் திறந்து:

- வகைப்படி செருகுநிரல்களை உலாவிப் பட்டியலில் தேடவும்.
- நீங்கள் விரும்புவனவற்றை நிறுவலாம் -- ஒவ்வொரு சொருகியும் தேவைக்கேற்ப பதிவிறக்கப்பட்டு SHA-256 சரிபார்ப்புத் தொகையால் சரிபார்க்கப்பட்டு செயலியின் தனியார் சேமிப்பில் வைக்கப்படுகிறது.
- நிறுவப்பட்ட சொருகிகளை அதே திரையிலிருந்தே இயக்கலாம்.

சொருகிகள் இயல்பாக ஒரு பொது பட்டியலிலிருந்து பெறப்படுகின்றன. நீங்களே ஒன்றை பராமரித்தால், Mobile SSH ஐ ஒரு தனிப்பயன் அல்லது தனியார் பட்டியல் மூலத்தை நோக்கிச் சுட்டலாம். நீங்கள் நம்பும் மூலங்களிலிருந்து மட்டுமே சொருகிகளை நிறுவவும்.

## மொழிகள்

Mobile SSH இயல்பாக முறைமை மொழியைப் பயன்படுத்தும். இரு செயலிகளிலும் இருபது மொழிகள்: அரபு, எகிப்திய அரபு, வங்காளம், சீனம் (எளிமைப்படுத்தியது/மரபுவழி), ஆங்கிலம், பிரெஞ்சு, ஜெர்மன், இந்தி, இந்தோனேசியம், ஜப்பானியம், மராத்தி, நைஜீரியப் பிஜின், போர்த்துகீசியம், ரஷ்யம், ஸ்பானிஷ், தமிழ், தெலுங்கு, துருக்கி, உருது.

தொலைபேசியின் மொழி அல்லாத வேறு மொழியில் செயலியை விரும்பினால், **Settings → Language** இல் "System default" விருப்பத்துடன் ஒரு தேர்வாளர் உள்ளது. Android இன் **Settings → System → Languages** இலிருந்தோ iOS இன் **Settings → General → Language & Region** இலிருந்தோ இன்னும் மாற்றவும் முடியும்.

## பாதுகாப்புக் குறிப்பு

நம்பக சேவையகத்தில் மட்டும் இணையவும். ஏற்றுமதி/பகிர்வு வரை தரவு சாதனத்திலேயே; Mobile SSH மேகப் பெட்டகம் அல்லது தானியங்கு சாதன ஒத்திசைவு தராது. சாதனமும் காப்பும் பாதுகாத்து, அறியாத கைரேகை சோதித்து, விசைமாற்றப் பிழையை ஆராய்ந்து மீண்டும் இணையவும்.
