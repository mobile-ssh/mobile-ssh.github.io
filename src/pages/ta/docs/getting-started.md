# தொடங்குதல்

Mobile SSH என்பது உங்கள் சொந்த Linux, Unix, நெட்வொர்க், IoT அல்லது டெவலப்மென்ட் சேவையகங்களுடன் இணைக்க உதவும் Android மற்றும் iOS க்கான ஒரு SSH கிளையன்ட். நீங்கள் சேவையக முகவரியையும் சான்றுகளையும் வழங்குகிறீர்கள்; செயலி ஒரு ஊடாடும் SSH டெர்மினலைத் திறக்கிறது.

## தேவைகள்

- Android 8.0 அல்லது புதியது, அல்லது iOS 16 அல்லது புதியது (iPhone அல்லது iPad).
- சாதனத்திலிருந்து உங்கள் SSH சேவையகத்திற்கு நெட்வொர்க் அணுகல்.
- SSH சேவையகத்தின் ஹோஸ்ட்பெயர் அல்லது IP முகவரி, போர்ட், பயனர்பெயர், மற்றும் கடவுச்சொல் அல்லது தனிப்பட்ட விசை.
- Android இல், தொலைபேசியின் உள்ளக கோப்பு உலாவியுடன் SFTP கோப்பு பரிமாற்றத்தைப் பயன்படுத்த விரும்பினால் சேமிப்பக அணுகல்; iOS அதற்குப் பதிலாக கணினியின் கோப்பு மற்றும் புகைப்படத் தேர்விகளைப் பயன்படுத்துகிறது.

## செயலியை நிறுவுதல்

- **Android:** Google Play இலிருந்து Mobile SSH ஐ நிறுவவும்.
- **iOS:** iOS செயலி TestFlight இல் பொது பீட்டாவாக வழங்கப்படுகிறது. Apple இன் TestFlight செயலியை நிறுவி, பின்னர் நிறுவவும் புதுப்பிப்புகளைப் பெறவும் தளத்தின் முகப்புப் பக்கத்திலிருந்து Mobile SSH அழைப்பு இணைப்பைத் திறக்கவும்.

## சேவையகத்துடன் இணைத்தல்

1. Mobile SSH ஐத் திறக்கவும்.
2. **+ Add Session** ஐத் தட்டி சேமித்த சேவையகத்தை தேடவும், அல்லது அந்தத் திரையிலிருந்தே புதிய சேவையகத்தைச் சேர்க்கவும்.
3. புதிய சேவையகம் சேர்க்கும்போது ஹோஸ்ட், போர்ட், பயனர்பெயர் மற்றும் அங்கீகார விவரங்களை உள்ளிடவும்.
4. டெர்மினல் அமர்வைத் திறக்க சேவையகத்தைத் தட்டவும்.
5. இன்னும் இயங்கும் அமர்வுகளுக்குத் திரும்ப தொடக்கத் திரையில் **Active Sessions** ஐப் பயன்படுத்தவும்.

இயல்புநிலை SSH போர்ட் `22`. உங்கள் சேவையகம் வேறு போர்ட்டைப் பயன்படுத்தினால், அந்த போர்ட்டை சேவையக சுயவிவரத்தில் உள்ளிடவும்.

## சேவையகங்களைச் சேமித்தல்

சேமித்த சேவையகங்கள் இணைப்பு இலக்கையும் விருப்பத் தேர்வான டன்னல் கட்டமைப்பையும் வைத்திருக்கின்றன. ஒரு சேமித்த சேவையகத்தில் இவை இருக்கலாம்:

- ஹோஸ்ட்பெயர் அல்லது IP முகவரி.
- SSH போர்ட்.
- பயனர்பெயர்.
- கடவுச்சொல் அல்லது தனிப்பட்ட விசை விவரங்கள்.
- விருப்பத் தேர்வான உள்ளக போர்ட்-ஃபார்வர்டிங் விதிகள்.
- அதே கணினிக்கான விருப்பத் தேர்வான கூடுதல் முகவரிகள் (கீழே காண்க).

நீங்கள் மீண்டும் மீண்டும் அணுகும் ஹோஸ்ட்களுக்கு சேமித்த சேவையகங்களைப் பயன்படுத்தவும். ஒரு சேமித்த சேவையகம் உங்கள் தற்போதைய செயலில் உள்ள அமர்வை விட வேறு ஹோஸ்ட்டை சுட்டிக்காட்டினால், Mobile SSH தேர்ந்தெடுத்த இலக்கிற்கு புதிய இணைப்பைத் தொடங்கும்.

### பல முகவரிகள் (LAN/VPN ரோமிங்)

நீங்கள் எங்கிருக்கிறீர்கள் என்பதைப் பொறுத்து அதே கணினியை பல்வேறு முகவரிகளில் அடிக்கடி அணுகலாம் — வீட்டு Wi-Fi IP-ஐ எதிராக VPN IP. மாற்று முகவரிகளை சேவையகத்தின் திருத்த உரையாடலில் சேர்க்கவும், தேவைப்பட்டால் ஒவ்வொன்றுக்கும் அதன் சொந்த போர்ட்டுடன். நீங்கள் இணைக்கும்போது, ஒன்று பதிலளிக்கும் வரை Mobile SSH முகவரிகளை வரிசையில் முயற்சிக்கிறது, மேலும் கடைசியாக வேலை செய்த முகவரியை நினைவில் வைத்து அடுத்த முறை அதை முதலில் அழைக்கிறது. ஒரு நெட்வொர்க் மாற்றம் (எடுத்துக்காட்டாக VPN-ஐ விட்டு வெளியேறுவது) செத்த வழி நேரம் முடிவடையும் வரை காத்திருக்காமல், தற்போது அணுகக்கூடிய முகவரிக்கு உடனடி மீள்-இணைப்பைத் தூண்டுகிறது.

## சான்றுகளைச் சேமித்தல்

**Credentials** திரை, மீண்டும் பயன்படுத்தக்கூடிய பயனர்பெயர்/கடவுச்சொல் அல்லது பயனர்பெயர்/தனிப்பட்ட-விசை பதிவுகளைச் சேமிக்கிறது. சேமித்த சான்றுகளை சேவையக அமைப்பு உரையாடலிலிருந்து தேர்ந்தெடுக்கலாம், இதனால் ஒவ்வொரு ஹோஸ்ட்டிற்கும் அதே உள்நுழைவுத் தகவலை மீண்டும் உள்ளிட வேண்டியதில்லை.

சான்று பதிவுகள் சாதனத்தில் உள்ளூரில் சேமிக்கப்படுகின்றன — iOS இல், ரகசியங்கள் கணினியின் Keychain இல் வைக்கப்படுகின்றன. கடவுச்சொற்கள், கடவுச்சொற்றொடர்கள் அல்லது தனிப்பட்ட விசைகளைச் சேமித்தால் சாதனத்தைத் திரைப் பூட்டால் பாதுகாக்கவும்.

## தனிப்பட்ட விசைகளைப் பயன்படுத்துதல்

Mobile SSH ஒட்டப்பட்ட தனிப்பட்ட விசைகளையும் கணினி கோப்பு தேர்வி மூலம் விசை இறக்குமதியையும் ஆதரிக்கிறது. Android இல் செயலி Ed25519, RSA, ECDSA மற்றும் DSA விசைகளை ஆதரிக்கிறது; iOS இல் Ed25519 மற்றும் ECDSA (P-256/384/521) விசைகளை ஆதரிக்கிறது.

தனிப்பட்ட விசையைப் பயன்படுத்த:

1. **Credentials** அல்லது சேவையக திருத்த உரையாடலைத் திறக்கவும்.
2. தனிப்பட்ட விசை உரையை ஒட்டவும், அல்லது **Import from file** ஐத் தேர்ந்தெடுக்கவும்.
3. விசை குறியாக்கம் செய்யப்பட்டிருந்தால் கடவுச்சொல்/கடவுச்சொற்றொடர் புலத்தில் விசை கடவுச்சொற்றொடரை உள்ளிடவும்.
4. சான்று அல்லது சேவையகத்தைச் சேமிக்கவும்.

தனிப்பட்ட விசை இறக்குமதி விசை கோப்புகளுக்கு கணினியின் கோப்பு தேர்வியைப் பயன்படுத்துகிறது. Android இல், கோப்பு பரிமாற்றம் ஒரு தனி உள்ளக கோப்பு உலாவியைப் பயன்படுத்துகிறது, புதிய Android பதிப்புகளில் பரந்த சேமிப்பக அணுகலைக் கோரலாம்; iOS இல், கோப்புகள் கணினியின் ஆவணம் மற்றும் புகைப்படத் தேர்விகள் வழியாக வருகின்றன.

## சமீபத்திய அமர்வுகள்

தொடக்கத் திரை சமீபத்திய அமர்வுகளைக் காட்டுகிறது. சமீபத்திய அமர்வு அதே சேவையக தொகுப்புடன் மீண்டும் இணைக்கலாம். முந்தைய அமர்வு இன்னும் செயலில் இருந்தால், Mobile SSH நகல் இணைப்பைத் தொடங்காமல் அதற்கே திரும்புகிறது.

## சேமித்த சேவையகங்களைத் தேடுதல்

**Saved Servers** பக்கத்தில் உள்ள தேடல் புலத்தைத் தட்டி பெயர் அல்லது ஹோஸ்ட் மூலம் வடிகட்டவும். **+ Add Session** திரையும் தேடலுடன் திறக்கப்படுகிறது, இதனால் ஒரே படியில் சேமித்த சேவையகத்தை கண்டுபிடித்து இணைக்கலாம்.

## செயலில் உள்ள அமர்வுகள்

அமர்வுகள் இயங்கும்போது, தொடக்கத் திரை எண்ணிக்கையுடன் **Active Sessions** ஐக் காட்டுகிறது. டெர்மினல் கட்டத்திற்குத் திரும்ப அதைத் தட்டவும். தொடர்ந்து இயங்கும் அறிவிப்பும் செயலில் உள்ள ஹோஸ்ட்களை பட்டியலிடுகிறது — அறிவிப்பில் ஒரு ஹோஸ்ட்டைத் தட்டினால் நேரடியாக அந்த டெர்மினலுக்குச் செல்லலாம்.

தொடக்கத் திரைக்குத் திரும்புவது செயலில் உள்ள SSH அமர்வுகளைத் துண்டிப்பதில்லை; பலகங்களை மூடுவது அல்லது டெர்மினல் செயல்பாட்டை முடிப்பது அவற்றைத் துண்டிக்கிறது.

## முதல் பயனுள்ள அமைப்புகள்

தொடக்கத் திரையிலிருந்து **Settings** ஐத் திறக்கவும் (அதற்கென்று தனிப்பக்கம் உண்டு):

- டெர்மினலைத் தட்டும்போது விசைப்பலகை தோன்ற வேண்டுமெனில் தட்டு-விசைப்பலகை காட்டு விருப்பத்தை இயக்கவும்.
- நீண்ட பின்னணி பணிகள் (Claude Code, Codex, ஷெல் ஸ்கிரிப்ட்கள்) இயக்கும்போது முகவர் உங்கள் உள்ளீட்டை எதிர்பார்க்கும்போது ஒலி அல்லது அதிர்வு அறிவிப்பு வேண்டுமெனில் **Agent alerts** ஐ இயக்கவும்.
- தரவு அனுப்பப்படுவதை விரும்பாவிட்டால் அநாமதேய பயன்பாட்டு பகுப்பாய்வை முடக்கவும்.

## மொழிகள்

Mobile SSH கணினி மொழியைப் பின்பற்றுகிறது. செயலி அரபு, பெங்காலி, சீனம் (எளிமைப்படுத்தப்பட்ட மற்றும் பாரம்பரிய), ஆங்கிலம், பிரஞ்சு, ஜெர்மன், இந்தி, இந்தோனேசியம், ஜப்பானியம், மராத்தி, நைஜீரிய பிட்ஜின், போர்த்துகீசியம், ரஷ்யன், ஸ்பானிஷ், தமிழ், தெலுங்கு, துருக்கியம் மற்றும் உருது மொழிபெயர்ப்புகளுடன் வருகிறது. மொழியை செயலிக்குள்ளிருந்து அல்ல, Android இன் **Settings → System → Languages** இலிருந்து, அல்லது iOS இல் **Settings → General → Language & Region** இலிருந்து மாற்றவும்.

## பாதுகாப்புக் குறிப்பு

நீங்கள் நம்பும் சேவையகங்களுடன் மட்டுமே இணைக்கவும். தற்போதைய செயலி சேமித்த இணைப்புத் தரவை உள்ளூரில் வைத்திருக்கிறது, கிளவுட் பெட்டகம் அல்லது சாதனங்களுக்கிடையேயான ஒத்திசைவை வழங்குவதில்லை. தற்போதைய நிர்வாகம் அறியப்பட்ட-ஹோஸ்ட் உறுதிப்படுத்தல் வேண்டுகோளையும் காட்டுவதில்லை, எனவே ஹோஸ்ட் அடையாளம் முக்கியமாகும்போது நம்பகமற்ற நெட்வொர்க்குகள் வழியாக இணைப்பதைத் தவிர்க்கவும்.
