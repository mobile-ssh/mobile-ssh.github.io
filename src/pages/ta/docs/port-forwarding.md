# போர்ட் ஃபார்வர்டிங்

Mobile SSH உள்ளக SSH போர்ட் ஃபார்வர்டிங்கை Android மற்றும் iOS இரண்டிலும் ஆதரிக்கிறது. சாதனத்தில் உள்ள ஒரு உள்ளக போர்ட் `127.0.0.1` இல் இணைப்புகளுக்காகக் காத்திருந்து, SSH இணைப்பு வழியாக ட்ராஃபிக்கை தொலைதூர ஹோஸ்ட் மற்றும் போர்ட்டிற்கு அனுப்புகிறது.

## சேமித்த டன்னல் தொடரியல்

போர்ட்-ஃபார்வர்டிங் விதிகள் காற்புள்ளியால் பிரிக்கப்படுகின்றன. ஒவ்வொரு உள்ளீடும் இரண்டு வடிவங்களில் ஒன்றைப் பயன்படுத்துகிறது:

```text
PORT
LOCAL:REMOTEHOST:REMOTE
```

சுருக்க வடிவம்:

```text
8080
```

இது சாதனத்தில் `127.0.0.1:8080` ஐப் பிணைத்து, சேவையகத்தின் பார்வையில் அதை `localhost:8080` க்கு அனுப்புகிறது.

முழு வடிவம்:

```text
3000:localhost:3000
```

இது சாதனத்தில் `127.0.0.1:3000` ஐப் பிணைத்து, SSH வழியாக தொலைப் பக்கத்தில் `localhost:3000` க்கு அனுப்புகிறது.

பல ஃபார்வர்டுகள்:

```text
8080, 3000:localhost:3000, 15432:db.internal:5432
```

## சேமித்த சேவையகத்தில் டன்னலைச் சேர்த்தல்

1. **Saved Servers** ஐத் திறக்கவும்.
2. சேவையக சுயவிவரத்தைச் சேர்க்கவும் அல்லது திருத்தவும்.
3. **Port forwards** இல் ஃபார்வர்டிங் விதிகளை உள்ளிடவும்.
4. சேவையகத்தைச் சேமிக்கவும்.
5. சேவையகத்துடன் இணைக்கவும்.

SSH அமர்வு இணைந்த பிறகு செயலி சேமித்த ஃபார்வர்டுகளைப் பயன்படுத்துகிறது.

## டன்னல்கள் சேவையக சுயவிவரத்திற்கே சொந்தம்

ஃபார்வர்டுகள் சேமித்த சேவையகத்தில் அறிவிக்கப்பட்டு, அந்த சேவையகம் இணைக்கும்போது எழுப்பப்படுகின்றன. அமர்வின் நடுவே ஒரு டன்னலைச் சேர்க்கவோ அகற்றவோ இரு தளங்களிலும் தனித் திரை எதுவும் இல்லை: உங்கள் ஃபார்வர்டுகளை மாற்ற, சேவையக சுயவிவரத்தைத் திருத்தி மீண்டும் இணையுங்கள்.

இது வேண்டுமென்றே செய்யப்பட்ட ஒரு பரிமாற்றம் — சுயவிவரத்தில் வாழும் ஒரு டன்னல், நீங்கள் இணைக்கும் ஒவ்வொரு முறையும் திரும்பி வருகிறது, புதிய நெட்வொர்க்கில் மீள்-இணைப்புக்குப் பிறகும் கூட, கையால் மீண்டும் கட்டாமலேயே.

## IPv6 இலக்குகள்

ஒரு IPv6 இலக்கு அடைப்புக்குறிக்குள் இருக்க வேண்டும், இதனால் முக்காற்புள்ளிகள் போர்ட் பிரிப்பானுடன் குழம்ப முடியாது:

```text
8080:[2001:db8::1]:80
```

அடைப்புக்குறி இல்லாத வெறும் IPv6 முகவரி அமைதியாகத் தவறாகப் படிக்கப்படுவதற்குப் பதிலாக தெளிவற்றது எனத் தள்ளுபடி செய்யப்படுகிறது. இதே அடைப்புக்குறி வடிவம் ஒரு சேவையகத்தின் முகவரி புலத்திலும் வேலை செய்கிறது, அதற்குப் பின் விருப்பப் போர்ட்டுடன் (`[fe80::1]:22`).

## முகவரி பிணைப்பு

Mobile SSH உள்ளக ஃபார்வர்டுகளை சாதனத்தில் `127.0.0.1` உடன் பிணைக்கிறது. இது வேண்டுமென்றே செய்யப்படுகிறது: இது டன்னலை சாதன-உள்ளகமாக வைத்து, IPv6 மட்டும் லூப்பேக் ஏற்படும் எதிர்பாராத சிக்கல்களைத் தவிர்க்கிறது. இயக்க முறைமை அவற்றின் நெட்வொர்க் அணுகலை அனுமதித்தால், அதே சாதனத்தில் உள்ள பிற செயலிகள் அனுப்பப்பட்ட உள்ளக போர்ட்டுடன் இணைக்க முடியும்.

## பொதுவான எடுத்துக்காட்டுகள்

தொலை சேவையகத்தில் இயங்கும் வலை சேவையை அணுகுதல்:

```text
8080
```

பின்னர் அதே சாதனத்தில் உலாவியிலிருந்து `http://127.0.0.1:8080` ஐத் திறக்கவும்.

டெவலப்மென்ட் சேவையகத்தை அணுகுதல்:

```text
3000:localhost:3000
```

SSH சேவையகத்திலிருந்து அணுகக்கூடிய உள் தரவுத்தளத்தை அணுகுதல்:

```text
15432:db.internal:5432
```

## டன்னல் சிக்கல் தீர்வு

- SSH அமர்வு இணைக்கப்பட்டுள்ளதா என்பதை உறுதிசெய்யவும் — அமர்வு எழுந்த பிறகே ஃபார்வர்டுகள் எழும்பும்.
- உள்ளக போர்ட் ஏற்கனவே பயன்பாட்டில் இல்லை என்பதைச் சரிபார்க்கவும்.
- தொலை ஹோஸ்ட் மற்றும் போர்ட் SSH சேவையகத்திலிருந்து அணுகக்கூடியவை என்பதைச் சரிபார்க்கவும்.
- இலக்கு சேவை SSH சேவையகத்திலேயே இருக்கும்போது `localhost` ஐப் பயன்படுத்தவும்.
- SSH சேவையகத்தின் பின்னால் உள்ள மற்றொரு ஹோஸ்ட்டிற்கு அனுப்பும்போது சேவையகத்தின் உள் DNS பெயர் அல்லது IP ஐப் பயன்படுத்தவும்.
